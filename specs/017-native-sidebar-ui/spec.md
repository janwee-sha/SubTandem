# 功能规格：原生侧栏视觉与语言自动保存

**功能分支**：`feat/ui_change`

**创建日期**：2026-08-25

**状态**：已完成

**输入**：将 SubTandem 侧栏收敛为接近 IINA/macOS 宿主的轻量视觉，移除 Target Language 的显式保存按钮，并让操作反馈由控件状态、领域状态和异常消息分层承担。

## 用户场景与测试（必填）

### 用户故事 1——选择目标语言即保存（优先级：P1）

用户在侧栏选择目标语言后，无需再点击保存按钮；选择会立即进入保存流程，成功由最终选中值确认，失败则恢复已提交值并明确说明。

**优先级理由**：该交互直接减少一次操作，并决定后续字幕翻译使用的目标语言。

**独立测试**：加载已有目标语言，选择另一个值，确认界面中不存在语言保存按钮，且只产生一次保存并在成功后保持新值。

**验收场景**：

1. **假如**侧栏已加载当前目标语言，**当**用户选择不同语言，**那么**系统立即发起一次保存并在等待期间阻止重复选择。
2. **假如**保存成功，**当**系统返回已提交语言及新修订号，**那么**新语言保持选中且界面不增加重复的可见成功消息。
3. **假如**保存失败、取消或无法完成，**当**系统返回结果，**那么**选择器恢复上一个已提交语言并显示失败反馈。
4. **假如**用户选择的值与已提交语言相同，**当**变更事件发生，**那么**系统不发起保存。

---

### 用户故事 2——侧栏融入 IINA/macOS 宿主（优先级：P2）

用户在亮色或暗色外观下打开 SubTandem 时，看到的是与 IINA 原生侧栏一致的平铺分区、原生尺寸控件和低对比分组材质；常规操作结果由控件状态表达，不再以长期成功文案形成额外视觉层级。

**优先级理由**：统一视觉层级能减少插件与播放器宿主之间的割裂感，并提升窄侧栏中的信息密度。

**独立测试**：分别在亮色和暗色外观下打开侧栏，按视觉验收项检查背景、分区、控件、开关、按钮、Profile 列表和 Session 信息。

**验收场景**：

1. **假如**IINA 使用亮色外观，**当**用户打开 SubTandem，**那么**侧栏继承宿主背景，内容使用全宽分区、细分隔线和紧凑原生控件。
2. **假如**IINA 使用暗色外观，**当**用户打开 SubTandem，**那么**文字、控件、分组材质和系统蓝高亮保持清晰且不过度发亮。
3. **假如**系统请求提高对比度、减少透明度或减少动态效果，**当**侧栏渲染，**那么**对应辅助功能偏好得到保留。
4. **假如**Translate、Target Language、Position、Profile Save/Update/Create/Select/Delete 或 Subtitle Retry 成功，**当**对应控件或内容已呈现权威结果，**那么**界面不再显示重复的可见操作成功消息。
5. **假如**上述操作仍在进行，**当**用户查看或使用原控件，**那么**禁用、忙碌属性、按钮文案或图标动画在控件内表达等待状态，不新增可见消息行。
6. **假如**操作失败、发生回滚或 Profile 与凭据只完成部分保存，**当**结果被当前请求接受，**那么**对应区域显示安全且可执行的异常说明。
7. **假如**用户测试 Profile 或刷新模型列表，**当**当前请求完成，**那么**Profile 卡片保留与当前 revision 绑定的 Test 状态，Model ID 区域保留模型数量、空目录或刷新失败状态，而不是显示通用操作完成文案。

### 边界情况

- 保存进行中收到旧的侧栏状态快照时，不覆盖用户正在等待提交的选择。
- 保存结果的请求标识与当前等待请求不一致时，不改变当前语言状态或反馈。
- 目标语言目录刷新时，继续按既有目录顺序显示选项，并保持已提交值。
- 侧栏宽度较小时，横向设置行回退为纵向排列，不产生横向溢出。
- 宿主未向插件网页暴露原生材质时，界面保持透明和低对比语义色，不伪造与视频内容绑定的动态取色。
- 可见成功消息被移除后，辅助技术仍可获知当前请求的进行中与成功终态；可见异常消息不得与同一结果重复播报。
- Profile 更新使当前选择失效时，卡片必须回到可选择状态；Test 状态不得跨 Profile revision 保留。
- 模型刷新返回与现有目录相同、空目录或失败时，状态必须仍能区分三种结果；失败不得清空上次成功目录。

## 需求（必填）

### 功能需求

- **FR-001**：界面 MUST 不再显示 Target Language 的显式保存按钮。
- **FR-002**：用户选择不同目标语言后，系统 MUST 立即发起一次保存。
- **FR-003**：一次目标语言保存等待结果期间，系统 MUST 阻止并发选择和重复保存。
- **FR-004**：目标语言保存成功后，系统 MUST 采用返回的已提交语言和修订号；选中值 MUST 作为可见成功结果，界面 MUST NOT 再显示重复的可见成功消息。
- **FR-005**：目标语言保存失败、取消或无法完成后，系统 MUST 恢复上一个已提交语言，并显示不会误导用户的失败反馈。
- **FR-006**：系统 MUST 忽略不属于当前目标语言保存请求的过期结果。
- **FR-007**：侧栏 MUST 使用透明宿主表面、全宽内容分区和细分隔线作为主要层级；宿主已显示插件标签时，内容区 MUST NOT 重复显示插件标题，Translate 开关 MUST 与 Subtitle 标题共用首个分区标题行。
- **FR-008**：仅紧密关联的 Profile 列表和 Session 信息 MAY 使用低对比半透明圆角分组材质；分组 MUST NOT 叠加独立 blur 或持续可见的外框。
- **FR-009**：控件、开关、按钮、字号、字重、边距与圆角 MUST 收敛到 IINA/macOS 窄侧栏的紧凑尺度；Translate 开关 MUST 使用 44×20px 轨道与 26×16px 胶囊形滑块；Position MUST 使用 20px 命中区内的 3px 中性轨道与 18×14px、7px 圆角的浅色矩形旋钮，不得保留 WKWebView 默认深色凹槽、正圆旋钮、额外描边或投影；表单控件 MUST 使用无持续描边的低对比透明语义填充，Target Language MUST 使用标签在上的全宽布局，Model ID 下拉框与自定义编辑框之间 MUST 保留 5px 垂直间距。
- **FR-010**：次要操作 MUST 使用低强调样式；主要操作和选中状态 MUST 使用 macOS 系统蓝语义；普通成功状态 MUST NOT 以整行高强调绿色文案呈现。
- **FR-011**：侧栏 MUST 保留提高对比度、减少透明度、减少动态效果和强制颜色模式的可访问性适配。
- **FR-012**：Profile 保存、翻译开关、字幕位置、模型发现及服务配置的消息字段、请求归属、持久化和业务结果 MUST 保持不变；本功能只改变 Sidebar 的反馈呈现。
- **FR-013**：Translate、Target Language、Position、Profile Save/Update/Create/Select/Delete 与成功的 Subtitle Retry MUST 以对应控件或内容的权威状态作为可见成功反馈，MUST NOT 保留重复的可见操作成功消息。
- **FR-014**：上述操作的等待状态 MUST 由对应控件的禁用状态、`aria-busy`、按钮忙碌文案或图标动画表达，MUST NOT 为等待状态新增可见消息行。
- **FR-015**：当前请求失败、发生回滚或形成 Profile 已保存但凭据未保存的部分成功时，系统 MUST 在所属区域显示安全且可执行的可见反馈；用户主动取消删除且业务状态未变化时 MAY 静默结束。
- **FR-016**：Profile Test MUST 在所属 Profile 卡片中显示与当前 revision 绑定的 `Not tested`、`Test passed` 或 `Test failed` 状态；成功 MUST NOT 追加句式操作消息，失败 MUST 同时显示安全的可执行原因，删除或 revision 更新 MUST 清除旧 Test 状态。
- **FR-017**：模型刷新等待期间 MUST 只使用刷新控件的忙碌状态；成功 MUST 在 Model ID 区域显示模型数量或空目录状态且使用低强调样式；失败 MUST 保留上次成功目录并显示安全的可执行原因。
- **FR-018**：Profile 更新使选择失效时，卡片 MUST 回到未选择状态并恢复可用的 Select 操作；完整保存成功 MUST 静默，Profile revision 已创建但凭据保存失败 MUST 明确说明部分成功。
- **FR-019**：被视觉隐藏的进行中与成功结果 MUST 继续通过单一辅助技术播报区域公布；可见失败反馈 MUST 保持与原控件的可访问关联，且同一结果不得重复播报。

### 关键实体

- **目标语言提交状态**：包含当前已提交语言、修订号、是否已加载以及当前等待请求，用于区分界面选择、已持久化值和过期结果。
- **侧栏视觉分区**：包含字幕与 Translate、翻译服务、Profile 列表和 Session 信息；每个分区只承担一种信息层级。
- **操作反馈层级**：区分控件内忙碌、权威界面状态、持久领域状态、可见异常和辅助技术播报，决定每类结果的唯一呈现位置。

## 成功标准（必填）

### 可衡量结果

- **SC-001**：用户从已加载状态选择不同目标语言后，无需额外点击，并且每次选择只产生 1 次保存尝试。
- **SC-002**：目标语言保存成功后的可见成功消息数量为 0；失败、取消和异常结果 100% 恢复已提交值并在对应区域显示明确反馈。
- **SC-003**：亮色和暗色验收中，顶层悬浮卡片数量为 0，Profile 与 Session 之外不出现独立玻璃分组。
- **SC-004**：在受支持的侧栏宽度下，所有表单控件均可见、可操作且无横向滚动。
- **SC-005**：Profile、翻译开关、字幕位置、模型发现和服务配置的请求、持久化与业务结果自动化回归全部通过。
- **SC-006**：覆盖全部 Sidebar 用户操作的验收中，状态可自证操作的可见 busy/success 消息数量为 0；Profile Test、模型数量或空目录及所有可执行失败结果均显示在所属区域，跨 revision 或迟到结果误更新次数为 0。
- **SC-007**：亮色和暗色宿主对比中，Position 的轨道与旋钮采用约 3px 和 18×14px 的宿主几何，旋钮为 7px 圆角矩形且不出现 WKWebView 默认深色凹槽、正圆轮廓、黑色外框或额外投影。

## 假设

- 本功能只移除 Target Language 的保存按钮；Profile 保存仍保留显式确认，避免扩大凭据与服务配置持久化边界。
- 保存通常很快完成，因此等待期间暂时禁用目标语言选择器比引入多请求队列更清晰。
- 保存失败时恢复已提交值，避免界面展示尚未生效的目标语言。
- 普通成功的辅助技术播报可保留固定英文文案，但不得重新占用可见布局。
- Profile Test 和模型目录属于用户后续决策所需的领域状态，不参与普通操作成功消息的静默规则。
- IINA 顶部插件切换条、原生侧栏材质和 WebView 外部区域由宿主管理，不属于插件可修改范围。
- 实机视觉验收由开发者分别在亮色和暗色外观下按明确步骤完成，不要求额外目标用户参与。

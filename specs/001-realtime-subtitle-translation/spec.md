# Feature Specification: SubTandem 实时字幕翻译 MVP

**Feature Directory**: `specs/001-realtime-subtitle-translation`
**Created**: 2026-08-09
**Status**: 已完成
**Input**: 为 IINA 提供按播放位置实时翻译外部文本字幕的双语字幕插件。

## User Scenarios & Testing

### User Story 1 - 观看实时双语字幕 (Priority: P1)

用户播放带外部 SRT 或 ASS 字幕的外语视频时，原字幕保持可见，母语译文作为第二字幕按原时间轴显示；翻译延迟或失败不得暂停视频。

**Independent Test**: 使用可控翻译服务播放 SRT 与 ASS 样本，验证译文时间、顺序、第二字幕归属以及失败时的连续播放。

**Acceptance Scenarios**:

1. **Given** 已确认源语言、母语和可用服务，**When** 开始播放，**Then** 临近字幕被翻译并作为第二字幕显示。
2. **Given** 字幕包含多行、重叠时间或 ASS 控制标记，**When** 译文生成，**Then** 时间和顺序保持一致，控制标记不作为正文显示。
3. **Given** 翻译延迟、失败或返回无效内容，**When** 原字幕到达，**Then** 视频和原字幕继续播放，第二字幕不显示占位、错配或技术错误。
4. **Given** 两个视频窗口同时翻译，**When** 任一窗口跳转、失败、禁用或关闭，**Then** 另一个窗口的状态、缓存和字幕不受影响。

### User Story 2 - 限制调用并复用当前会话译文 (Priority: P2)

用户只希望翻译实际观看位置附近的非母语字幕，并在当前视频会话内复用成功译文，以控制费用和外发内容范围。

**Independent Test**: 使用记录请求的服务执行连续播放、前后跳转、重播、禁用和关闭，验证语言门控、前瞻边界、缓存复用与会话清理。

**Acceptance Scenarios**:

1. **Given** 字幕与母语相同，**When** 播放或跳转，**Then** 不调用翻译服务并显示无需翻译。
2. **Given** 用户只观看长视频的一部分，**When** 连续播放，**Then** 请求不超出当前播放位置后的 120 秒或 40 条字幕。
3. **Given** 当前会话已成功翻译一段字幕，**When** 向后跳转重播且相关输入未变，**Then** 直接复用缓存且不重复调用。
4. **Given** 用户快速跳转、禁用翻译、换片或关闭视频，**When** 旧请求迟到，**Then** 旧结果不写入当前字幕，当前视频缓存按生命周期清理。

### User Story 3 - 配置并切换翻译服务 (Priority: P3)

用户可以创建、测试、选择、编辑和删除 OpenAI-compatible 或 Ollama Profile，并清楚了解目标地址、凭据状态、连接结果和操作结果。

**Independent Test**: 从空白设置分别配置两类服务，测试连接、选择、翻译、编辑、删除、重启和服务切换，验证安全边界与结果隔离。

**Acceptance Scenarios**:

1. **Given** 用户填写有效地址和模型，**When** 保存并测试 Profile，**Then** 显示独立的凭据保存状态和连接结果。
2. **Given** 用户选择远程 Profile，**When** 开始翻译，**Then** 只向界面披露的地址发送必要字幕内容；地址变化后必须重新选择。
3. **Given** 用户编辑或删除 Profile，**When** 操作完成，**Then** 不产生重复 Profile，删除同时撤销相关凭据、授权、缓存服务和在途工作。
4. **Given** 操作在途或结束，**When** 会话状态刷新，**Then** 控件的 loading、成功、取消或错误反馈不会被覆盖。

### Edge Cases

- 没有字幕、字幕不可读或格式不受支持时，不发送内容并显示可操作状态。
- 字幕为空、损坏、编码异常或条目时间无效时，忽略不安全条目且不阻断播放。
- 源语言未知时，要求用户确认后才能发送字幕。
- 服务部分返回、重复 ID、缺失 ID、空文本或不可解析内容时，只接受可明确映射的有效结果。
- 网络中断、超时、限流或本地服务退出时，原视频和字幕继续可用，并按限定策略处理临时失败。
- 用户手动更改第二字幕轨时，插件不得覆盖或删除不属于自己的轨道。

## Requirements

### Functional Requirements

- **FR-001**: 插件 MUST 读取当前选中的、可访问的外部 SRT 或 ASS 字幕，并保留条目文本、顺序和起止时间。
- **FR-002**: 用户 MUST 能设置母语并确认源语言；源语言未知时 MUST 阻止外发，相同语言默认不翻译。
- **FR-003**: 翻译范围 MUST 以播放位置为中心且不超过之后 120 秒或 40 条；余量低于 30 秒或 10 条时补充下一批。
- **FR-004**: 插件 MUST 批量处理临近字幕，并限制单批工作量；不得在开始观看时预翻译整部视频。
- **FR-005**: 跳转、配置变化、禁用、换片或关闭 MUST 使不再相关的工作失效，迟到结果不得写入当前会话。
- **FR-006**: 有效译文 MUST 作为插件拥有的第二字幕显示，保持原时间和顺序，不替换原字幕或用户选择的其他轨道。
- **FR-007**: 插件 MUST 在当前视频会话缓存成功译文，并按视频、字幕版本、语言和 Profile revision 隔离；会话结束时立即清空。
- **FR-008**: 产品 MUST 仅提供 OpenAI-compatible 与 Ollama 两类翻译 Profile，并支持保存、测试、选择、编辑和确认删除。
- **FR-009**: OpenAI-compatible API root MUST 原样保存和展示；界面 MUST 预览实际请求地址，地址变化后必须重新选择。
- **FR-010**: 远程服务凭据 MUST 由插件专用本地存储持久化，输入保持 write-only，不得进入偏好设置、安装包、状态、日志或可复制诊断。
- **FR-011**: 产品 MUST 明确披露本地凭据文件的权限保护与剩余风险；Ollama Profile 不保存凭据。
- **FR-012**: 服务请求 MUST 只包含临近字幕文本、语言方向、opaque ID 和最少必要上下文，不包含视频内容或无关用户数据。
- **FR-013**: 每条服务结果 MUST 与请求 ID 明确对应；缺失、重复、空白、未知或无效结果不得缓存为成功。
- **FR-014**: 临时失败 MUST 在首次尝试后最多重试 3 次，逐次延长等待并遵守服务提供的等待时间；过期工作不得继续重试。
- **FR-015**: 用户 MUST 能查看无需翻译、等待配置、准备、运行、部分失败和服务不可用状态，并能随时启用或禁用翻译。
- **FR-016**: 每个 IINA 窗口 MUST 使用独立的播放上下文、请求、重试、缓存、状态和第二字幕轨。
- **FR-017**: helper 空闲退出后，下一次敏感操作 MUST 在发送服务请求前恢复新会话；已派发的服务请求不得自动重放。
- **FR-018**: 每个 Profile MUST 提供使用系统代理与明确直连两种路由；正式验收 MUST 使用可卸载安装包。
- **FR-019**: 同一窗口结束视频后 MUST 保留可复用控制器，并能在随后打开视频时建立全新会话。
- **FR-020**: 所有可执行 Sidebar 控件 MUST 提供 request-correlated 的在途和终态反馈。

### Key Entities

- **播放会话**: 单个播放器窗口内的视频、字幕源、语言、位置、epoch、缓存、状态和自有第二字幕轨。
- **字幕源与条目**: 字幕内容身份以及带文本、顺序和时间范围的 cue 集合。
- **Provider Profile**: 服务类别、显示名、地址、模型、代理模式、revision、凭据状态和窗口选择状态。
- **翻译批次**: 有限 cue 集合、语言方向、Profile revision、请求身份和生命周期状态。
- **缓存项**: 当前会话内按字幕、语言和 Profile 身份隔离的成功译文。

### Scope Boundaries

**In Scope**:

- 外部 SRT/ASS、实时有限前瞻、OpenAI-compatible/Ollama、当前会话缓存和第二字幕显示。
- 多窗口隔离、Profile 管理、凭据保护、代理路由、helper 恢复和正式安装包。

**Out of Scope**:

- 音频转写、图形字幕、整片预翻译、译文编辑或导出、持久译文缓存和云同步。
- 同一窗口同时翻译多个字幕轨或输出多个目标语言。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 服务在 3 秒内返回有效批次时，首条译文在播放开始后 5 秒内准备完成；首批后至少 95% 的字幕在显示前已有译文，插件造成的暂停为 0。
- **SC-002**: 长视频只观看前 10 分钟时，所有请求均处于实际位置之后 120 秒或 40 条以内，且不包含其余视频字幕。
- **SC-003**: 母语字幕测试中的服务调用为 0；已完整翻译片段重播时至少 99% 的条目命中缓存，成功条目的重复调用为 0。
- **SC-004**: SRT 与 ASS 样本中，100% 的成功译文保持正确时间、顺序、窗口、语言和 Profile 对应关系。
- **SC-005**: 两类服务均可在 3 分钟内从空白完成配置、测试和选择，常见配置错误无需查看日志即可采取下一步操作。
- **SC-006**: 超时、限流、断网、无效返回和本地服务退出场景均保持视频连续播放；每个临时失败批次的额外尝试不超过 3 次。
- **SC-007**: 两个窗口并发执行播放、跳转、切换、禁用和关闭时，100% 的结果、缓存、状态和字幕更新仅作用于所属窗口。
- **SC-008**: 20 次 Profile 编辑和删除循环不产生重复项；所有操作均显示在途和终态反馈，同一窗口连续打开视频均建立新会话。
- **SC-009**: helper 空闲至少 310 秒后，凭据操作、服务测试和实际翻译均恢复新会话，已派发服务请求的自动重放次数为 0。
- **SC-010**: 至少 9/10 名目标用户无需开发者协助即可完成母语设置、服务选择、播放外语字幕和看到第二字幕的主任务。

## Assumptions

- 用户运行 IINA 1.4+，并自行管理所选服务、模型、网络、费用和内容政策。
- 语言地区变体默认按基础语言判断，除非用户明确选择不同目标语言。
- 成功译文只存在于当前视频会话；外部服务的质量和响应时间不由插件保证。

# 功能规格：自定义译文浮层垂直位置

**功能目录**：`specs/016-customize-overlay-position`

**创建日期**：2026-08-23

**状态**：已完成

**输入**：在插件设置页提供与 IINA 字幕位置配置相近的可拖动位置条，允许用户以 0 至 100 的数值调整 SubTandem 译文浮层的相对垂直位置并实时预览；全屏时是否使用黑边作为定位区域跟随 IINA“全屏时将字幕显示在黑边”的配置。

## 澄清

### 会话 2026-08-23

- Q: 实时预览位置后，应在什么时候将新位置持久保存？ → A: 拖动期间只预览；松手或完成一次键盘调整后自动保存，保存失败时恢复最后保存值。
- Q: 如果多个设置页几乎同时调整同一个全局位置，最终值应如何确定？ → A: 最后发起且保存成功的调整生效；所有设置页和浮层同步，迟到的旧响应被忽略。
- Q: SubTandem 应复现 IINA/mpv 的定位与顶部钳制语义，还是让译文块在可移动范围内严格线性移动？ → A: 复现 IINA/mpv 语义：以译文块底部定位，多行向上扩展，靠近顶部时按块高度钳制。
- Q: 当播放器因画面比例产生上下黑边时，位置值应以哪个垂直区域为基准？ → A: 全屏时跟随 IINA“全屏时将字幕显示在黑边”的配置：启用时包含上下黑边，禁用时限制在实际视频画面区域内。

### 会话 2026-08-24

- Q: 是否允许新增宿主 Overlay 权限，以按译文实际布局完成多行块底部定位和顶部钳制？ → A: 允许新增 `video-overlay` 权限并迁移到可精确测量实际布局的宿主 Overlay；本功能仍不支持在播放器画面直接拖动译文，Overlay MUST 保持非交互。
- Q: 宿主 Overlay 与迁移前 `osd-overlay` 的字体度量不同时，应保持相同名义字号还是相同视觉大小？ → A: 以迁移前 `osd-overlay` 的可见字形为基准，固定校准宿主 Overlay 的字号与字重，使两种方案在同一窗口高度下视觉接近；该校准不新增用户可配置样式。

## 用户场景与测试

### 用户故事 1：拖动位置条并实时预览（优先级：P1）

用户打开插件设置页后，希望通过鼠标或触控板直接拖动位置条调整译文浮层的垂直位置，并在播放画面中立即看到当前译文随数值移动，以便快速避开画面主体、原字幕或其他信息。

**优先级理由**：可拖动配置与实时预览共同构成本功能的核心价值；缺少任一项都会迫使用户反复试错或无法直观判断位置。

**独立测试**：在当前播放窗口显示一条译文，打开插件设置页并从 0 依次拖动到 50 和 100；核对数值、位置条状态和译文位置是否同步变化，即可完整验证主要用户价值。

**验收场景**：

1. **假如** 当前播放窗口正在显示译文且设置页已打开，**当** 用户通过鼠标按下后拖动或触控板纯拖动位置条，**那么** 页面同步显示 0 至 100 范围内的当前整数值，译文浮层在拖动过程中实时移动到对应的相对垂直位置。
2. **假如** 当前值为 0，**当** 用户向数值增大的方向拖动，**那么** 译文从靠近当前有效垂直定位区域顶部的位置连续向底部移动，不出现反向移动或非预期跳变。
3. **假如** 当前值为 100，**当** 译文内容能够容纳在当前有效垂直定位区域内，**那么** 译文块底部使用 IINA 当前原生字幕底边距；值为 0 时译文块顶部对齐该区域顶部，不额外应用 OSD 纵向边距。
4. **假如** 当前播放位置没有可显示的译文，**当** 用户调整位置，**那么** 页面仍更新并保存有效数值，但不为了预览而生成虚构译文；下一条有效译文直接显示在新位置。
5. **假如** 触控板纯拖动已改变位置条数值，**当** 本次拖动结束且用户没有再单击位置条，**那么** 最终值仍自动保存一次，并在重开设置页后恢复。
6. **假如** IINA 原生字幕与 SubTandem 位置值同时设为 0 或同时设为 100，**当** 两者显示在同一有效垂直定位区域，**那么** 译文不得因额外 OSD 纵向边距而比原生字幕继续向画面内侧收缩。

---

### 用户故事 2：以后继续使用所选位置（优先级：P2）

用户完成位置调整后，希望该选择成为 SubTandem 的通用译文位置，关闭设置页、切换媒体或重新打开 IINA 后无需重复配置。

**优先级理由**：位置属于用户偏好；若不能稳定保留，实时调节只能带来单次会话价值。

**独立测试**：将位置设为一个非默认值，依次关闭设置页、切换媒体并重新启动 IINA；每次显示译文并重新打开设置页，核对浮层与控件是否保持同一数值。

**验收场景**：

1. **假如** 用户将位置调整为任一有效值，**当** 用户关闭并重新打开设置页，**那么** 位置条显示最后保存的值，当前和后续译文沿用该位置。
2. **假如** 用户已保存非默认位置，**当** 用户切换媒体、关闭播放窗口或重新打开 IINA，**那么** 新播放会话中的译文继续使用该值。
3. **假如** 用户从未设置位置或已有安装中尚无该配置，**当** 首次加载本功能，**那么** 译文继续使用升级前的顶部默认位置，设置页显示数值 0。
4. **假如** 一个无效、缺失或超出范围的历史配置被读取，**当** 设置页或译文浮层初始化，**那么** 产品安全回退到默认值 0，不显示在范围外的位置。

---

### 用户故事 3：不同播放状态下保持相对位置（优先级：P3）

用户调整位置后，希望译文在窗口缩放、全屏切换及多个播放窗口中都保持同一相对垂直位置，不因显示环境变化而回到默认位置。

**优先级理由**：相对位置只有跨常见播放状态保持一致，才能成为可信赖的长期偏好。

**独立测试**：保存一个中间值，在窗口模式、全屏模式、不同窗口尺寸及两个同时播放的窗口中显示译文，并在全屏存在上下黑边时分别启用和禁用 IINA“全屏时将字幕显示在黑边”；核对每个浮层的相对垂直位置、有效定位区域和设置值是否一致。

**验收场景**：

1. **假如** 用户已设置一个非默认位置，**当** 播放窗口改变尺寸或切换全屏，**那么** 译文按当前有效垂直定位区域保持同一位置值对应的相对垂直位置，不回到默认位置。
2. **假如** 多个播放窗口同时显示译文，**当** 用户在任一设置页调整全局位置，**那么** 所有当前可见译文都实时采用新位置，后续译文也使用同一值。
3. **假如** 某个播放窗口没有当前译文，**当** 另一个窗口调整位置，**那么** 无译文窗口不显示预览文本，但其下一条有效译文使用最新位置。
4. **假如** 全屏画面存在上下黑边且正在显示译文，**当** 用户启用或禁用 IINA“全屏时将字幕显示在黑边”，**那么** 译文分别按包含黑边或仅包含实际视频画面的区域重新定位，SubTandem 的位置数值保持不变。
5. **假如** 当前译文通过宿主 Overlay 显示，**当** 用户在译文及其周围画面单击、双击、拖动窗口或使用播放器快捷键，**那么** IINA 的既有播放与窗口交互保持不变，译文不接受输入也不能在画面中被直接拖动。
6. **假如** 使用同一窗口高度、字体和译文内容对照迁移前 `osd-overlay`，**当** 宿主 Overlay 显示译文或窗口等比缩放，**那么** 可见字形的大小与字重保持视觉接近，并随窗口高度等比缩放。
7. **假如** 位置为 0 或 100 且全屏黑边配置处于任一状态，**当** 用户退出全屏、关闭窗口、重载插件或退出 IINA，**那么** SubTandem 不得在宿主 mpv 已开始关闭后读取其属性，不得导致 IINA 崩溃、退出受阻或弹出崩溃报告。

### 边界情况

- 用户将位置条拖到或键盘调整到 0、100 时，值必须被接受且端点可稳定复现。
- 拖动指针越出位置条范围时，当前值保持在最近端点，不产生小于 0 或大于 100 的值。
- 用户连续快速往返拖动时，只显示当前最新位置，不在松开后回放过时的中间位置。
- 同一次拖动产生多个结束信号时只能保存一次；拖动未结束时不得因短暂停顿保存中间值。
- 多个设置页几乎同时提交位置时，按保存请求发起顺序采用最后成功的调整；较早请求的迟到响应不得覆盖较新值或导致位置回跳。
- 译文包含多行或接近可用高度时，位置变化不得改变既有字体、字号、颜色、换行与内容规则；内容本身高于可见区域时继续遵循现有裁切边界。
- 多行译文以整个译文块的底部为定位基准并向上扩展；靠近顶部时按译文块高度钳制，因此连续的较小数值允许对应同一顶部安全位置，但不得反向移动。
- 全屏画面没有上下黑边时，切换 IINA“全屏时将字幕显示在黑边”不得造成译文位置非预期跳变；有黑边时，切换配置只改变有效定位区域，不改变已保存的位置值。
- 调整时恰好发生译文更新、清除、跳转、换片或禁用翻译时，实时预览不得恢复过期译文、生成占位文本或阻塞播放。
- 保存位置失败时，页面应明确告知用户未能保存，并继续使用最后一个已确认有效的持久位置；不得把失败值伪装成已保存状态。
- 用户在译文或周围画面执行点击、双击、窗口拖动和快捷键操作时，Overlay 不得获得焦点、截获输入或改变播放器行为。
- 某个可选 mpv 几何或 margin 属性缺失、读取失败时，其他已成功读取的几何和黑边配置必须继续生效；不得因单个属性失败把有效视频区域整体回退为完整窗口。
- 退出全屏、关闭窗口、重载插件和退出 IINA 期间可能继续到达窗口尺寸事件或定时任务；这些入口不得在 mpv shutdown 或窗口关闭开始后读取属性，所有位置几何刷新必须先停止并失效。

## 需求

### 功能需求

- **FR-001**：插件设置页 MUST 将包含目标语言和译文位置设置的区域标题显示为 `Subtitle`，将位置条标签显示为 `Position`，并提供专用于 SubTandem 译文浮层垂直位置的可拖动位置条；交互形式和方向 MUST 与 IINA 字幕位置配置保持一致。
- **FR-002**：位置值 MUST 为 0 至 100 的整数且包含两个端点；0 MUST 使能够容纳的译文块顶部对齐当前有效垂直定位区域顶部，100 MUST 使译文块底部对齐扣除 IINA 当前原生字幕底边距后的边界，数值增大 MUST 使译文单调向下移动。
- **FR-003**：设置页 MUST 始终向用户显示位置条的当前数值，并使显示值、位置条状态、待保存偏好和用户可见译文位置保持一致。
- **FR-004**：用户通过鼠标按下后拖动、触控板纯拖动或位置条支持的键盘操作改变数值时，当前可见译文 MUST 在交互过程中实时采用最新有效位置；拖动结束或完成一次键盘调整后，系统 MUST 自动且仅持久保存一次最终值，不得要求额外的点击或保存操作，也不得在拖动短暂停顿时保存中间值。
- **FR-005**：没有当前有效译文时，位置调整 MUST 正常生效并保存，但 MUST NOT 为预览生成示例译文、源字幕副本、占位文本或其他虚构内容。
- **FR-006**：位置偏好 MUST 作为插件范围的全局用户设置持久保留，并适用于当前及后续所有播放窗口、媒体和播放会话。
- **FR-007**：所有当前显示译文的播放窗口 MUST 在位置变化时采用最新有效值；没有当前译文的窗口 MUST 在下一条有效译文出现时采用该值；其他已打开的设置页 MUST 同步显示该值。
- **FR-008**：用户从未保存该设置、配置缺失或读取到非整数及范围外值时，系统 MUST 使用默认值 0，以保持升级前的顶部译文位置。
- **FR-009**：位置偏好 MUST 在设置页重新打开、媒体切换、播放窗口重建、窗口尺寸变化、全屏切换和 IINA 重新启动后保持一致。
- **FR-010**：译文位置 MUST 采用与 IINA/libass `sub-pos` 一致的块底部定位语义，多行内容 MUST 向上扩展；Main MUST 使用当前 `sub-margin-x`、`sub-margin-y` 与 `sub-margin-y-offset`，不得以 `osd-margin-x/y` 代替。对于能够完整容纳在当前有效垂直定位区域内的译文，100 MUST 在底部保留当前有效原生字幕纵向边距，0 MUST 不应用该纵向边距并把整个译文块钳制在区域顶部，且数值增大时不得反向移动。
- **FR-011**：位置调整 MUST 只改变译文浮层的相对垂直位置，MUST NOT 改变其横向居中、字体、字号、颜色、背景、描边、内容、换行、显示时序或会话归属规则。
- **FR-012**：位置调整与保存失败 MUST NOT 阻塞视频、原字幕或翻译流程，不得恢复过期译文；保存失败时 MUST 将位置条、显示数值和所有译文浮层恢复到最后一个已确认有效的持久值，并向用户提供明确反馈。
- **FR-013**：本功能 MUST 保留既有译文隐私与生命周期边界；位置设置和预览 MUST NOT 持久化字幕或译文正文，也不得新增网络目的地或扩大正文外发范围。
- **FR-014**：多个设置页并发保存全局位置时，系统 MUST 按请求发起顺序以最后发起且保存成功的调整为最终值；较早请求的迟到成功或失败响应 MUST NOT 覆盖较新的成功值、回退控件或移动译文浮层。
- **FR-015**：全屏存在上下黑边时，当前有效垂直定位区域 MUST 跟随 IINA“全屏时将字幕显示在黑边”的当前配置：启用时 MUST 包含上下黑边，禁用时 MUST 限于实际视频画面区域；配置或全屏状态变化时 MUST 以同一 SubTandem 位置值重新定位当前及后续译文，MUST NOT 改写该位置偏好。没有上下黑边时，两种配置状态 MUST 产生相同的有效定位区域。
- **FR-016**：译文浮层 MUST 声明新增的 `video-overlay` 权限并迁移到非交互式宿主 Overlay，以实际渲染块尺寸执行 FR-010 的定位与钳制；Overlay MUST NOT 接受鼠标、触控或键盘输入，也不得改变播放器既有点击、拖动、全屏和快捷键行为。
- **FR-017**：宿主 Overlay 的固定字号与字重 MUST 以迁移前 `osd-overlay` 在同一窗口高度下的可见字形为基准进行校准，使两种渲染方案的字形大小和笔画粗细在视觉上接近；字号 MUST 随窗口高度等比缩放，且位置调整、内容长度和换行 MUST NOT 改变该视觉基线。
- **FR-018**：Main MUST 独立读取并缓存 `osd-dimensions`、字幕 margin 和黑边配置，单个属性缺失或读取失败 MUST NOT 丢弃其他有效输入；`osd-dimensions` 与 `sub-use-margins` MUST 在活动播放器中以不高于 100 毫秒的周期检测变化，且仅在有效区域变化时重排。普通 Overlay viewport resize MUST 仅由 WebView 使用缓存区域重排；全屏事件 MUST 使用事件状态和缓存输入重排，MUST NOT 为此重新读取 mpv。`mpv.shutdown` 或窗口开始关闭时 MUST 先停止动态检测并封闭缓存，之后不得调用 mpv 属性 API。

### 关键实体

- **译文浮层垂直位置偏好**：插件范围的持久用户选择；有效值为 0 至 100 的整数，默认值为 0，并决定所有播放窗口中译文块的相对垂直位置。
- **位置预览状态**：用户当前正在设置页选择的最新有效值；用于即时更新可见译文，在确认持久化前不得被误报为已保存。
- **有效垂直定位区域**：当前显示状态下用于解释 0 至 100 位置值的垂直范围；全屏存在上下黑边时由 IINA 的黑边字幕配置决定是否包含黑边，范围变化不改变位置偏好本身。
- **译文浮层**：既有的逐播放窗口译文显示表面；本功能只改变其垂直位置，内容、时间归属、安全显示和清理规则保持不变。

### 范围边界

**范围内**：

- 在插件设置页新增 0 至 100 的译文垂直位置条、当前数值显示和键盘可操作能力。
- 使用 `Subtitle` 区域标题和 `Position` 位置标签；鼠标按下后拖动与触控板纯拖动期间均实时预览当前有效译文的位置，并在拖动结束后自动保存。
- 持久保留全局位置，并同步当前及后续播放窗口。
- 在窗口缩放、全屏、换片和重启后保持相对位置，并在全屏时跟随 IINA 的黑边字幕配置解释定位区域。

**范围外**：

- 在播放器画面上直接拖动译文浮层。
- 自定义横向位置、对齐、字体、字号、颜色、背景、描边、透明度或样式预设。
- 为无当前译文的场景生成示例预览文本。
- 改变字幕提取、翻译服务、请求批次、缓存、译文内容、显示时序或播放器字幕轨。
- 为不同 Profile、媒体或播放窗口保存不同位置。

## 成功标准

### 可衡量结果

- **SC-001**：单名开发者在 10 次首次尝试中，10 次均能在 30 秒内找到位置设置、将译文移到指定的顶部、中部或底部区域，并准确说出当前数值。

- **SC-003**：对 0、25、50、75、100 各重复设置 10 次时，显示值、位置条状态和可见译文相对位置的一致率为 100%；数值增大时译文不得反向移动，因多行译文顶部钳制而连续保持同一顶部位置不计为失败；与 IINA 原生字幕同时设置 0、100 时，由额外 OSD 纵向边距造成的端点内缩必须为 0 像素。

- **SC-005**：在窗口模式、全屏模式、包含上下黑边的画面比例、IINA 黑边字幕配置启用与禁用、至少 20 次尺寸变化和两个并行播放窗口中，所有能够容纳在各自有效垂直定位区域内的译文均保持所选位置值对应的相对位置并完整可见；配置状态与定位区域不一致、意外恢复默认位置、位置值被改写和窗口间不一致次数均为 0。

## 假设

- 本设置为插件范围的全局偏好，而不是按 Profile、媒体或播放窗口分别保存。
- 为与 IINA 字幕位置的用户心智保持一致，位置值从顶部向底部递增：0 对应顶部，100 对应底部；设置页位置条从低值到高值排列。
- 译文块沿用 IINA/mpv 的块底部定位与顶部钳制语义，而不是按译文块高度把全部 101 个数值重新线性分配到可移动范围；顶部端点不应用 `MarginV`，底部端点使用当前原生字幕 margin。
- 全屏时是否把上下黑边纳入有效垂直定位区域，跟随 IINA“全屏时将字幕显示在黑边”的当前配置；该宿主配置不属于 SubTandem 的持久位置偏好。
- 默认值 0 对应当前版本既有的顶部译文位置，因此升级后尚未配置的用户不会看到位置变化。
- “实时预览”指更新当前真实有效译文的位置；没有当前译文时不展示示例内容，下一条译文使用最新值。
- 触控板纯拖动与鼠标按下后拖动共享同一位置意图、完成和保存语义，不引入按设备类型区分的偏好。
- 现有译文浮层继续提供横向居中、固定样式、换行、内容安全、播放时序、清理与多窗口隔离能力；跨渲染方案保持的是可见字形的视觉基线，不要求沿用相同的名义字号参数。
- 本功能需要新增 `video-overlay` 权限并把译文渲染迁移到非交互式宿主 Overlay；不新增网络访问，也不扩大字幕与译文数据保留范围。新增权限、Overlay 消息和持久位置偏好均需在规划和实现阶段接受契约、隐私与打包回归验证。
- IINA 的窗口尺寸和全屏事件可能晚于 mpv 生命周期；位置实现通过活动期变化检测补齐宿主无法可靠观察的 node/flag 属性，并在 `mpv.shutdown` 或窗口关闭开始时先停止检测和解除监听。

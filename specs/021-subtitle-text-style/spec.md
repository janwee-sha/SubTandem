# 功能规格：字幕文本样式设置

**功能目录**：`specs/021-subtitle-text-style`

**创建日期**：2026-09-01

**状态**：草案

**输入**：在侧栏 `Subtitle` 区域提供参考 IINA 原生字幕设置的译文文本样式配置，支持 Font 的 Color、Size、Font、Bold、Italic，Border 的 Color、Width，Background 的 Color，以及紧凑色盘和完整系统颜色面板。

## Clarifications

### Session 2026-09-01

- Q: 当多个已打开侧栏在保存完成前修改同一组全局样式时，系统应如何合并这些修改？ → A: 不同字段合并；同一字段以最后一次有效编辑为准。
- Q: 当已保存的字体后来不可用时，系统回退到默认字体后应如何处理原字体偏好？ → A: 保留原字体偏好；临时回退，重新可用后自动恢复。
- Q: 样式保存失败并回退后，`Subtitle` 区域必须向用户提供哪种恢复操作？ → A: 仅显示错误；用户需重新修改设置。
- Q: 当用户在 Size 或 Width 中输入空值、非整数或范围外数值后离开控件时，系统应如何处理该编辑？ → A: 改用 IINA 有限下拉项；Size 40 映射原 Size 29，Width 3 映射原 Width 2。
- Q: 除 Size `40 → 29` 和 Width `3 → 2` 两个默认锚点外，其余有限选项应如何确定对应的 SubTandem 渲染值？ → A: 根据两个默认锚点按比例换算所有选项。

## 用户场景与测试（必填）

### 用户故事 1——自定义译文字体（优先级：P1）

用户希望在 `Subtitle` 区域调整译文的颜色、字号、字体、粗体和斜体，并立即观察当前译文的变化，从而在不同视频内容、观看距离和显示设备下保持清晰可读。

**优先级理由**：字体决定译文最基本的可读性，也是本功能能够独立交付的最小用户价值。

**独立测试**：显示一条 SubTandem 译文，依次修改 Font 下的五项设置，确认控件值与画面中的译文同步；取消字体选择时画面与已保存值均不改变。

**验收场景**：

1. **假如**当前窗口正在显示译文，**当**用户选择 Font Color、调整 Size 或切换 Bold、Italic，**那么**当前译文立即采用最新有效值，字幕内容、时序、横向居中和已保存 Position 不变。
2. **假如**用户打开 Font 选择器，**当**用户筛选并确认一个可用字体，**那么**译文采用所选字体，Font 控件显示该选择；取消时保持打开选择器前的字体。
3. **假如**用户首次使用本功能或从不含样式偏好的版本升级，**当**译文显示，**那么**Font Size 下拉项默认为 40，其渲染效果与升级前的 Size 29 一致；字体默认为白色系统字体、非粗体、非斜体。

---

### 用户故事 2——增强译文与画面的分离度（优先级：P2）

用户希望为译文设置描边颜色和宽度，并设置文字背景颜色，使浅色、深色或画面细节复杂的场景中仍能辨认译文。

**优先级理由**：描边和背景是复杂画面中的主要可读性补偿手段，在字体设置之上提供完整的字幕样式控制。

**独立测试**：在明暗元素同时存在的画面上调整 Border Color、Border Width 和 Background Color，确认描边与紧贴译文块的背景分别变化，Width 为 0 时不再显示描边。

**验收场景**：

1. **假如**当前窗口正在显示译文，**当**用户改变 Border Color 或 Width，**那么**全部可见译文使用对应描边，Width 为 0 时不残留固定描边或替代轮廓。
2. **假如**当前窗口正在显示单行或多行译文，**当**用户改变 Background Color，**那么**背景只覆盖译文文本块所占区域，不扩展为遮挡画面的整层区域。
3. **假如**用户从不含样式偏好的版本升级，**当**首次加载设置，**那么**Border 默认为黑色，Width 下拉项默认为 3 且渲染效果与升级前的 Width 2 一致，Background 默认为透明，整体视觉保持升级前状态。

---

### 用户故事 3——通过色盘选择并长期复用样式（优先级：P3）

用户希望三个 Color 控件都能使用与 IINA 相近的紧凑色盘快速选色，也能打开完整系统颜色面板精细选色；完成的整套样式应在所有播放窗口和以后会话中继续使用。

**优先级理由**：统一选色流程与持久化使样式从临时预览变为可复用的全局观看偏好。

**独立测试**：分别从预设色盘和完整颜色面板为 Font、Border、Background 选色，重开侧栏、切换媒体并重启 IINA，确认三个色样、其他样式值及所有窗口中的译文一致。

**验收场景**：

1. **假如**用户激活任一 Color 色样，**当**紧凑色盘打开，**那么**用户可选择预设颜色或透明色，也可通过 `Show Colors…` 打开完整系统颜色面板，且选色只修改该 Color 字段。
2. **假如**用户从紧凑色盘选择颜色，或在完整系统颜色面板中调整颜色，**当**侧栏仍打开，**那么**对应色样与当前可见译文同步显示新颜色；打开选色界面后未改变颜色便关闭时保持原值。
3. **假如**用户已保存一组有效样式，**当**侧栏重开、媒体切换、窗口新建或 IINA 重启，**那么**所有八项样式值继续生效；多个当前播放窗口采用同一组最新样式。
4. **假如**一次样式保存失败，**当**系统处理失败结果，**那么**控件和所有译文恢复最后确认保存的整组样式，并在 `Subtitle` 区域提供明确反馈，视频、原字幕和翻译流程继续运行。

### 边界情况

- Size 只提供 30、35、40、45、50、55、60、65、70，Width 只提供 0、0.25、0.5、1、1.5、2、2.5、3、4、5；两个控件均不得接受自定义数值。
- 快速连续调整同一字段时，画面只采用最新有效预览；过期的保存结果不得覆盖较新的成功值或造成样式回跳。
- 点击紧凑色盘或系统颜色面板外部时必须关闭该选色界面；已有 native picker 时再次请求任一 picker 必须静默将活动窗口置于顶端，不得报错或留下不可见 busy 状态。
- 当前没有有效译文时仍可调整并保存样式，但不得为预览生成示例译文、源字幕副本或占位文字。
- 所选字体在之后不可用时，MUST 保留已保存的原字体偏好并临时使用默认系统字体渲染，侧栏明确显示当前正在使用回退字体；该字体重新可用后 MUST 自动恢复，其他样式值保持不变。
- 所选字体没有独立粗体或斜体字形时，使用该字体最接近的可用呈现，不得导致译文消失或阻塞播放。
- 字号、字形或字重使译文换行或高度变化时，译文仍遵循现有横向居中、Position 定位、可见区域钳制和裁切规则。
- Font 与 Background 均为透明且 Border Width 为 0 或 Border Color 透明时，允许译文不可见；产品不得静默改写用户选择。
- 色盘、字体选择器或保存操作失败时，已保存样式和当前播放必须保持可用，错误反馈不得包含字幕正文。

## 需求（必填）

### 范围边界

- 本功能只设置 SubTandem 自行渲染的译文浮层，不修改 IINA 原字幕、源字幕文件或字幕轨样式。
- 本功能只增加文本样式配置及其预览、同步和持久化，不改变翻译服务、字幕内容、显示时序、Position 数值或 Overlay 的非交互边界。
- 不包含按媒体、窗口、Profile 或字幕轨分别保存样式，也不包含导入、导出、主题预设或一键重置。

### 功能需求

- **FR-001**：侧栏 MUST 将全部译文文本样式设置放在现有 `Subtitle` 区域的 Position 之后，并在该区域按 `Font`、`Border`、`Background` 分组；其他区域 MUST NOT 重复出现这些设置。
- **FR-002**：`Font` 分组 MUST 提供 `Color`、`Size`、`Font`、`Bold` 和 `Italic`；Size MUST 使用有限单选下拉控件，Bold 与 Italic MUST 分别使用可独立切换的勾选框。
- **FR-003**：`Border` 分组 MUST 提供 `Color` 和 `Width`，Width MUST 使用有限单选下拉控件；`Background` 分组 MUST 提供 `Color`。
- **FR-004**：三个 `Color` 控件 MUST 显示当前颜色色样，并提供同一套 IINA 风格紧凑色盘；色盘 MUST 包含预设颜色与透明色，并提供 `Show Colors…` 入口打开完整系统颜色面板；点击紧凑色盘外部 MUST 关闭色盘且不得改值。
- **FR-005**：从紧凑色盘选择颜色后 MUST 直接应用；完整系统颜色面板中的变化 MUST 实时预览，并在面板关闭时保留最后选择；点击系统颜色面板外部 MUST 关闭面板。两种入口都 MUST 保留颜色与透明度，且一次选色 MUST 只改变发起选色的 Font、Border 或 Background 字段；打开后未作更改便关闭 MUST 保持原值。
- **FR-006**：`Font` 控件 MUST 打开字体选择器，允许用户筛选可用字体、查看所选字体预览并确认或取消；只有确认 MUST 改变并保存字体。已有颜色或字体 picker 时再次请求任一 picker MUST 静默将活动窗口置于顶端，不得显示冲突错误或阻塞后续交互。
- **FR-007**：Size MUST 只提供 30、35、40、45、50、55、60、65、70，Width MUST 只提供 0、0.25、0.5、1、1.5、2、2.5、3、4、5；SubTandem 的 Size 渲染值 MUST 为所选 Size 乘以 `29/40`，Width 渲染值 MUST 为所选 Width 乘以 `2/3`，因此 Size 40 与 Width 3 MUST 分别呈现原 Size 29 与 Width 2 的视觉效果；Width 0 MUST 完全关闭描边。
- **FR-008**：用户改变任一有效样式时，所有当前可见的 SubTandem 译文 MUST 在不等待下一条 cue 的情况下预览最新值；没有当前译文时 MUST 正常保存但不得生成预览文本。
- **FR-009**：样式偏好 MUST 作为插件范围的全局设置持久保存，并适用于当前及后续所有播放窗口、媒体与 IINA 会话；多个侧栏在保存完成前修改不同字段时 MUST 合并各字段的有效修改，修改同一字段时 MUST 采用最后一次有效编辑；所有已打开侧栏 MUST 最终显示同一组已确认样式。
- **FR-010**：新安装、配置缺失或旧版本升级时 MUST 使用以下默认值：Font Color 白色、Size 40、Font 系统默认、Bold 关闭、Italic 关闭、Border Color 黑色、Width 3、Background Color 透明；Size 与 Width MUST 按 FR-007 的映射保持升级前译文视觉。
- **FR-011**：设置读取到无效字段时 MUST 仅将该字段回退到 FR-010 的默认值，其他有效字段 MUST 保留；不可用字体 MUST 按边界情况回退显示且不得破坏已保存的其他字段。
- **FR-012**：一次样式交互完成后 MUST 自动保存最终有效值，不要求额外保存按钮；保存等待状态 MUST 由所属控件表达，保存成功 MUST 由控件与译文的最终状态表达；界面 MUST NOT 显示 `Saving fontColor`、`Saving bold`、`Saving italic` 等例行操作消息。
- **FR-013**：保存失败 MUST 恢复最后确认保存的整组样式，并在 `Subtitle` 区域显示明确的非阻塞错误反馈；系统 MUST NOT 保留失败值或提供重试操作，用户重新修改后才可再次保存；失败、迟到或乱序结果 MUST NOT 阻塞播放、覆盖较新成功值或恢复过期译文。
- **FR-014**：文本样式变化 MUST 保持现有字幕内容、时序、横向居中、Position 偏好、有效定位区域、会话归属与非交互行为；由字体度量引起的换行和块高度变化 MUST 继续遵循既有布局边界。
- **FR-015**：所有样式控件、紧凑色盘和字体选择流程 MUST 可通过键盘完成，并提供可辨识的名称、当前值、焦点状态和高对比度外观；选色不得只依赖色样辨识。
- **FR-016**：样式设置、预览和保存 MUST NOT 持久化字幕或译文正文，不得新增网络目的地、扩大正文外发范围或把正文写入错误反馈。

### 关键实体

- **字幕文本样式**：插件范围的全局偏好，包含 Font Color、Size、Font、Bold、Italic、Border Color、Width 和 Background Color 八个字段，以及默认值和各字段有效性。
- **颜色选择目标**：当前发起选色的 Font、Border 或 Background 字段，关联其原值、预览值和已确认值，保证选色不会串改其他字段。
- **样式提交状态**：区分当前预览样式、最后确认保存样式、等待中的保存与失败回退，用于同步多个侧栏和播放窗口并拒绝过期结果。

## 成功标准（必填）

### 可衡量结果

- **SC-001**：在侧栏验收中，八项要求的样式值 100% 位于 `Subtitle` 区域，其他区域中的重复项数量为 0。
- **SC-002**：单个开发者无需外部说明即可在 2 分钟内分别完成字体、描边和背景设置，并能从控件状态准确识别当前八项值。
- **SC-003**：对当前可见译文执行 50 次覆盖全部字段的有效调整时，至少 95% 在 200 毫秒内呈现最新预览，且字幕内容错误、位置偏好改写和播放中断次数均为 0。
- **SC-004**：预设色盘、`Show Colors…` 和字体选择器三条流程的应用、未更改关闭或取消、目标字段隔离验收通过率为 100%。
- **SC-005**：保存有效样式后，重开侧栏、切换媒体、新建播放窗口和重启 IINA 四种场景中的八项值恢复率均为 100%。
- **SC-006**：无效输入、字体不可用、选色失败和保存失败的验收中，安全回退率为 100%，视频、原字幕和翻译流程阻塞次数为 0。
- **SC-007**：仅使用键盘可完成全部八项设置；亮色、暗色和提高对比度外观下，所有控件的名称、值、焦点与选中状态均可辨识。

## 假设

- “字幕文本样式”指 SubTandem 的译文浮层；IINA 原字幕继续由用户在 IINA 中独立设置。
- IINA 参考截图用于约束分组、控件语义、紧凑色盘、`Show Colors…` 和字体选择流程，不要求逐像素复制宿主界面。
- 颜色包含透明度；透明背景是保持当前无背景视觉并满足常见字幕需求的合理默认。
- 样式与现有 Position 一样属于全局观看偏好，而不是媒体或窗口专属数据。
- 当前译文 Overlay、`Subtitle` 区域、Position 同步与偏好保存能力是本功能的既有依赖。
- 实机视觉与交互验收由单个开发者按明确步骤完成，不需要额外目标用户参与。

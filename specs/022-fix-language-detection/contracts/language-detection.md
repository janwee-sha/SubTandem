# 本地检测与翻译准入契约

对应 FR-001–005、FR-010–011、SC-001–003、SC-005–006；实体和身份见 [数据模型](../data-model.md)。

## 正文输入与可靠性

1. 仅接收生产字幕准备成功后的非空 cue 集合，沿用 parser 按 `startMs/index` 排序的结果。轨道标签、文件名和旧手动源语言偏好不进入分类输入。读取/提取失败继续走字幕准备错误，不生成空翻译任务。
2. 检测副本去除无效证据，完全重复的准备后正文最多采纳一次，不把重复正文全部删除，也不改变待翻译条目。数字、标点、链接等无语言证据的正文可以用于后续未知源语言翻译。
3. 样本上限固定为 64 个有效独立 cue、4096 个 UTF-16 码元（含分隔符）。两项均在范围内时保留全部有效正文；任一超限均从时间轴四个区域均衡取样，包括只有 63/64 个 cue 但正文超长的轨道。区域只控制覆盖，不作为可靠性门禁；空白和重复 cue 不占有效 cue 名额。单个超长 cue 也保留前后区域覆盖。按码点安全截取，避免拆开代理对。
4. 样本按正文顺序分成每片 ≤2048 码元、总数至多 4 的片段；不直接把超限拼接字符串交给 franc。检测副本内的证据区间互不重叠，保留在样本中的起止位置及候选证据；区间总长度受同一采样预算约束，不复制正文增加权重。短样本允许只分类一次，不要求固定匹配片段数。
5. 使用标准 `franc@6.2.0` 完整候选集合；分数是相对距离，不能解释为概率或语言占比。证据归属须通过校准冻结的有效文字量、候选距离及分差规则；混合片段不能把全部文字直接记给整体第一名。无法可靠归属的区间标为未归属，不能按脚本、相邻语言或少数候选强配。缺少第二候选也不能仅因第一名为 1 就可靠。
6. 有效文字按 Unicode `Letter` 码点计数，数字、标点、空格、分隔符和组合附加符号不计权；检测副本中每个字母最多贡献一次。归一化[固定映射](../research.md#2-固定源语言映射)中的宏语言身份后汇总可靠归属的文字量，未映射模型代码保留独立身份及竞争作用。总有效文字量包含未归属文字，用于报告占比；选择仅比较各候选的可靠文字量，不能把未归属量分摊给赢家。
7. 选择可靠文字量唯一最高且自身证据充分的主要语言；不要求超过总量 50% 或任何固定支持比例。最高者并列为 `unknown/ambiguous`，文字不足为 `unknown/insufficient-evidence`，没有可用模型为 `unknown/unsupported`；最高者不可映射则为 `unknown/unmapped`，不能退选次高的可映射语言。没有可靠归属但文字充分时为 `unknown/ambiguous`。源结果不推断中文简繁或葡萄牙地区。
8. 删除 `minimumScriptRatio`、`minimumSupport`、固定 cue 下限、固定匹配窗口数、50 次幂和旧脚本拒绝路径。文字系统可用于构造证据或校准分层，不能用主要脚本占比决定可靠性，包括单候选路径。人名、无语义内容及罗马字歌词须通过同一证据可靠性判断；不硬编码样本短语、语言标签或样本 ID。

| 正文条件 | 预期 |
| -------- | ---- |
| 同脚本或跨脚本可靠文字量为 55:45、40:35:25 | 选择唯一最高语言，不使用过半或固定支持比例门禁 |
| cue 数最多的语言与有效文字量最多的语言不同 | 按有效文字量选择 |
| 最高可靠文字量并列或无法获得充分证据 | 保留未知，不以顺序或脚本打破并列 |
| 自然正文、译文、人名及罗马字歌词共存 | 正文和译文分别计权；未可靠归属的部分不强配，重复正文只贡献一次 |

上述归属仅服务本地轨道级判断，不新增逐 cue 产品接口、外发数据、持久状态或翻译语义校验。

## 校准门禁

先完成开放许可[语料记录](../data-model.md#验收语料与冻结记录)的采集、许可、真值和清单冻结。新一轮开发校准前，冻结 T050 的校准、独立留出及混合语义版本；校准须包含多个独立作品、相近语言、文字量充分的负样本及实际超过 2048 码元的自然正文。两个指定短轨所属作品不得进入校准。七个 FFmpeg 指定回归按[本地回归契约](local-regressions.md)独立验收，其正文或许可入库不是此前置条件。实现阶段只用校准集比较有界阈值组合，按作品分组验证，按错误可靠率约束优先、正确可靠率其次、规则简单度最后确定参数；搜索轴不得包含已取消的占比或匹配片段门禁。

先冻结搜索规则、参数及摘要，再执行独立留出验收。留出集按完整作品及全部译本与开发材料隔离，至少包含 20 种语言各 20 个独立单语自然正样本，保留规定分层。分别统计 SC-001 的三个分母；混合主语言另列预标结果及错误/未知率，不补数或稀释单语质量门。已评估清单及正文保留可复现，标记为已知回归用途；两个指定短轨和七个本地回归单列 SC-002，不能称作未见留出样本。

不得依据验收样本结果修改其真值、移出失败项、复制正文或针对样本加特判；混合预期改变时必须先依据正文建立新的语义版本及归属依据，不覆盖已冻结标注。未达到 SC-001/002 时保持未验收；再次校准须先建立另一独立冻结留出版本，不能重复使用已经评估的作品宣称独立验收。

## deadline 与生命周期

正文就绪时固定 `deadlineAt = sourceReadyAt + 500 ms`，作为正文就绪到翻译准入释放的验收上限；另设 `workDeadlineAt = sourceReadyAt + 450 ms`，作为检测工作的内部停止时间。重入和配置变化不得重置上述时间。

| 事件                    | 必须发生的行为                                                                                                                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 正文就绪                | Main 记录 `sourceReadyAt` 并启动唯一 attempt；计时包含采样、调度和分类，启动前检查 owner 和内部停止时间                                                                                  |
| 执行片段                | 预处理每批最多扫描 128 个 cue，较大文本拆分；在工作片段间让出事件循环，前后及提交时检查 owner、内部停止时间和取消状态                                                                    |
| 可靠/未知/异常          | 只向当前 owner 提交一次终态；异常转 `unknown/error`，不能留下永久 detecting                                                                                                              |
| 达到内部停止时间        | 不再启动采样或分类片段；尚未提交终态时立即提交一次 `unknown/timeout`，并同步触发当前位置的翻译准入检查。独立唤醒安排在内部停止时间，不能等到 500 ms 才开始释放准入；晚到结果不得覆盖终态 |
| 换轨/换片/正文改变      | 旧 attempt 失效；新正文使用新的 owner 和正文就绪时间                                                                                                                                     |
| 已生效目标/Profile 变化 | 使待完成 attempt 失效；同一正文已提交的判断继续使用，未完成则为当前配置设 `unknown/interrupted`，不重新开始 500 ms 等待                                                                  |
| 普通 seek               | 保留同正文检测；翻译请求仍按新的 `windowEpoch` 取消和提交                                                                                                                                |
| 禁用/关闭/结束播放      | 取消活动工作、清理状态与会话数据；重新启用仍经过正常字幕准备条件                                                                                                                         |

50 ms 是拟议的调度余量，必须通过 Node 和宿主测量验证，不能视为同步调用或宿主调度的最坏耗时保证。定时器无法抢占正在执行的同步片段；任何实际等待超过 500 ms 的验收样本均判为失败，即使随后正确转入未知源语言也不能豁免。

首次检测 p95 ≤100 ms、热检测 p95 ≤50 ms、同步片段 p99 ≤16 ms 的预算继续适用。若内部预算导致正确可靠率下降，仍须满足 SC-001/002，不得通过降低识别指标或排除超限样本验收。每个正文 owner 的未知终态不因 tick、重试、Sidebar 轮询而重新检测；没有独立远程语言识别请求。

## UI 与翻译准入

| 条件                   | 状态/行为                                                            |
| ---------------------- | -------------------------------------------------------------------- |
| 用户禁用               | `disabled`，无请求                                                   |
| 无可读正文             | 保留字幕准备状态或 `waitingForSubtitle`，无请求                      |
| 无有效选择或目标       | `waitingForConfiguration`，无请求；配置条件优先于检测提示            |
| 当前 attempt 未终结    | `detectingLanguage`，达到内部停止时间即按上述规则终结                |
| 检测任意终态且配置有效 | `preparing`，使用可靠 ID 或 `null` 请求当前服务，包括同语言          |
| 有正常结果/服务失败    | `running` 或既有 `partialFailure/serviceUnavailable`，按现有规则处理 |

删除 `languageUnrecognized`、`languageUnsupported`、`noTranslationNeeded` 的状态定义、消息接受集合和 Sidebar 文案。`source.detectedLanguage` 为安全 ID 或 `null`，未知标签仅描述源语言信息。复用当前 Sidebar 组件及 Overlay 样式，不新增源语言输入或交互控件。

# 本地检测与翻译准入契约

对应 FR-001–005、FR-010–011、SC-001–003、SC-005–006；实体和身份见 [数据模型](../data-model.md)。

## 正文输入与可靠性

1. 仅接收生产字幕准备成功后的非空 cue 集合，沿用 parser 按 `startMs/index` 排序的结果。轨道标签、文件名和旧手动源语言偏好不进入分类输入。读取/提取失败继续走字幕准备错误，不生成空翻译任务。
2. 检测副本去除无效证据，完全重复的准备后正文最多采纳一次，不把重复正文全部删除，也不改变待翻译条目。数字、标点、链接等无语言证据的正文可以用于后续未知源语言翻译。
3. 样本上限固定为 64 个有效独立 cue、4096 个 UTF-16 码元（含分隔符）。范围内的短轨保留全部有效正文；长轨从时间轴四个区域均衡取样，区域只控制覆盖，不作为可靠性门禁。按码点安全截取，避免拆开代理对。
4. 样本按正文顺序分成每片 ≤2048 码元、总数至多 4 的片段；不直接把超限拼接字符串交给 franc。短样本允许只分类一次，长样本聚合所有片段的有效文字权重和候选证据，不能要求至少几个匹配片段。
5. 使用标准 `franc@6.2.0` 完整候选集合；片段分数是相对距离，不能解释为概率。先分析可靠性，再按[固定映射](../research.md#2-固定源语言映射)得到产品源语言；宏语言归一化允许汇总同一身份的支持，未映射候选必须保留竞争作用。
6. 可靠性规则使用去重后有效文字量、候选分差、文字系统分布及可用片段冲突，参数按正文量/脚本分层。移除固定 cue 下限、固定匹配窗口数、50 次幂和旧脚本拒绝路径。缺少第二候选也不能仅因第一名为 1 就可靠；不能推断中文简繁或葡萄牙地区。

## 校准门禁

先完成 [语料记录](../data-model.md#验收语料与冻结记录)的采集、许可、真值和清单冻结。实现阶段只用校准集比较上述特征的有界阈值组合，按错误可靠率约束优先、正确可靠率其次、规则简单度最后确定参数，固定搜索范围、选择规则和结果配置后再评估验收集。

必须分别统计规格要求的三个分母及全部分层，保留未知结果。不得依据验收样本结果修改其真值、移出失败项、复制正文或针对样本加特判；未达到 SC-001/002 时保持未验收。若需要重新校准，必须重新建立独立的冻结验收版本，不能把已经用于调参的正文继续称作留出数据。

## deadline 与生命周期

| 事件 | 必须发生的行为 |
| --- | --- |
| 正文就绪 | Main 记录 `sourceReadyAt` 并启动唯一 attempt；计时包含采样、调度和分类 |
| 执行片段 | 预处理每批最多扫描 128 个 cue，较大文本拆分；在工作片段间让出事件循环，前后检查 owner、deadline 和取消状态 |
| 可靠/未知/异常 | 只向当前 owner 提交一次终态；异常转 `unknown/error`，不能留下永久 detecting |
| 到达 500 ms | 有独立 deadline 唤醒；进入 `unknown/timeout` 并释放翻译准入，晚到结果不得覆盖。提交时立即调度一次当前位置翻译，无需等用户操作 |
| 换轨/换片/正文改变 | 旧 attempt 失效；新正文使用新的 owner 和正文就绪时间 |
| 已生效目标/Profile 变化 | 使待完成 attempt 失效；同一正文已提交的判断继续使用，未完成则为当前配置设 `unknown/interrupted`，不重新开始 500 ms 等待 |
| 普通 seek | 保留同正文检测；翻译请求仍按新的 `windowEpoch` 取消和提交 |
| 禁用/关闭/结束播放 | 取消活动工作、清理状态与会话数据；重新启用仍经过正常字幕准备条件 |

定时器不能抢占同步 franc；单次同步片段必须单独满足 p99 ≤16 ms，同时首次/热检测 p95 ≤100/50 ms。上述实机预算不是以 500 ms 降级替代。每个正文 owner 的未知终态不因 tick、重试、Sidebar 轮询而重新检测；没有独立远程语言识别请求。

## UI 与翻译准入

| 条件 | 状态/行为 |
| --- | --- |
| 用户禁用 | `disabled`，无请求 |
| 无可读正文 | 保留字幕准备状态或 `waitingForSubtitle`，无请求 |
| 无有效选择或目标 | `waitingForConfiguration`，无请求；配置条件优先于检测提示 |
| 当前 attempt 未终结 | `detectingLanguage`，仅在 deadline 内等待 |
| 检测任意终态且配置有效 | `preparing`，使用可靠 ID 或 `null` 请求当前服务，包括同语言 |
| 有正常结果/服务失败 | `running` 或既有 `partialFailure/serviceUnavailable`，按现有规则处理 |

删除 `languageUnrecognized`、`languageUnsupported`、`noTranslationNeeded` 的状态定义、消息接受集合和 Sidebar 文案。`source.detectedLanguage` 为安全 ID 或 `null`，未知标签仅描述源语言信息。复用当前 Sidebar 组件及 Overlay 样式，不新增源语言输入或交互控件。

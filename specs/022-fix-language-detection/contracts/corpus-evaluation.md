# 契约：自然语料、冻结与评估

## 准入与集合隔离

1. 逐件保存有再分发许可的自然字幕、固定来源、修订/哈希、作者/译者、署名及许可依据，纳入 `tests/fixtures/languages/`。公开下载链接、轨道标签和未经核验的聚合语料均不足以准入；不依赖私有媒体。
2. 开发者核对正文语言、书写形式、自然片段边界和分层；可参照来源正文、可靠译文或语言资料，但不以本检测器输出反推真值。无法核对的片段保持待准入，不要求额外招募多名验收者。
3. 先按作品、译本谱系、相邻片段、镜像及派生版本建立来源组，再指定 `calibration` 或 `acceptance`。同源内容不跨集合；字幕文件哈希和规范正文哈希查重，还需人工检查译本及相邻片段，不能只比较不同文件名。
4. 调参前冻结两个集合的正文、真值、内容分层、正样本归属及来源组。冻结验收由独立来源组成；配置选择不得读取其结果。
5. 合成边界样本、格式转换、重新分段/计时和由多个自然片段构成的受控混合样本单独登记派生关系，不能充当新增独立自然片段。自然作品本身的重复歌词保留，但不以循环模板、复制 cue 或附加编号满足数量要求。

实体字段及状态见 [data-model.md](../data-model.md)，来源候选见 [research.md](../research.md)。

## 冻结覆盖矩阵

| 维度 | 最小覆盖与准入规则 |
| --- | --- |
| 源语言 | 至少 20 种，每种累计至少 20 条未经复制扩充的自然 cue；初始采集清单为 `en/de/fr/es/pt/it/hu/sv/ru/uk/pl/cs/nl/tr/ar/fa/ja/ko/zh/ha` |
| 正样本长度 | 按原始 cue 数分 5–11、12–30、≥31 三组，每组至少 20 个独立自然片段；不能靠分段变体补数量 |
| 指定回归 | 德语 11 cue、约 332 字母；英语 ASS 约 38 cue；hu/it/ru/sv 各约 19 cue；正文充分的 5–6 cue 拉丁文字和高区分文字样本 |
| 非典型内容 | 罗马字日语、自然豪萨语、真实混合语言、共享文字、短句/专名、片头片尾和重复歌词；低置信度样本保留在分母 |
| 混合比例 | 多数、40/35/25、范围内最高占比并列；范围外单一语言或合计占优、范围内少量文字、范围内外等比；cue 数和时长与文字量相反；同 cue/跨 cue、成团/交错、超过采样上限；精确比例可另用受控派生边界样本 |
| 中文 | 简体、繁体、仅能确定中文、形式证据冲突；中文主导且含少量 Kana，以及多语言共享文字 |
| 无候选/范围外 | 1–4 cue、稀少文字、纯空白/数字/符号/网址、无候选注入；正文可确认仅属范围外的 fi/he/no 及其他语言，覆盖纯单语和仅范围外混合正文 |
| 入口与变体 | 外挂 SRT/ASS；内嵌 SubRip/ASS/SSA/`mov_text`；正确/缺失/错误标签；分段与时长配对变体 |

校准集也必须包含上述语言及内容、长度分层，并与验收来源隔离。真值充分性和正样本归属先人工确定；不能看到误判后改为“文字不足”。指定回归无法取得原授权时使用合法自然替代，需保留对应缺陷分布，不能只满足 cue 数而换成干净句子模板。

每个自然片段拥有唯一 `statisticalUnitId`；平行译本、同正文格式和分段变体保留共同谱系，不伪装为额外独立来源。每个统计身份在冻结前指定唯一 `primarySampleId`，准确率与分层分母只取该主样本，其余译本/变体另作回归。主样本自身必须满足至少 20 种语言、每种至少 20 个自然 cue 及三长度组各 20 个片段的覆盖，不能借辅助变体补足。两集合均覆盖真实混语，受控 40/35/25 组合不能替代它。

## 四类结果与分母

对每个独立片段必须产生且只产生一类结果：

| 类别 | 计算 |
| --- | --- |
| 正确识别 | `reliable`，语言及要求的书写形式属于人工真值按 FR-004 确定的预期结果集合；混合正文取范围内最高文字量占比语言，即使范围外占比更高 |
| 错误识别 | `reliable`，但语言/形式不属于上述预期集合，或无有效文字/可确认仅属范围外正文被识别为受支持语言 |
| `unknown` | 实测返回 `unknown`，即使符合预期也不计正确识别 |
| `unsupported` | 实测返回 `unsupported`，即使符合预期也不计正确识别 |

四类计数之和必须等于对应组全部独立片段数。分别报告整体、每种语言、原始长度组及罗马字/歌词、混合、共享文字等标签组的分子、分母与比例；内容标签可重叠，总体不重复计数。罗马字日语被识别为豪萨语时，翻译资格可以正确，但识别仍是错误。

另外报告行为断言：是否应选择候选、是否应拒绝外发、主语言是否为范围内最高占比、范围内平票是否稳定、分段/时长/格式/标签的一致率。范围外占优且有范围内候选时应选候选，再按目标等价规则决定是否翻译。派生变体只进入成对回归分母；不能重新计入独立片段准确率。零分母或未覆盖组标为未完成，不填 100%。

## 校准与验收纪律

- 参数搜索直接调用生产核心，按[检测契约](language-detection.md)选择配置；校准报告与配置哈希在首次冻结验收前确定。
- 冻结验收将所有片段的四类结果完整输出；禁止按置信度、歌词、混合、拒绝结果或错误方向过滤分母。SC-001 的正样本总体及三个长度组分别要求 ≥95%，同分母拒绝合计 ≤5%；其余阈值按规格 SC-002–SC-006。
- SC-003 单独检查全部必过回归；SC-004 从生产正文入口进入协调器、controller 和本地受控 Provider，覆盖未启用、未选择/失效 Profile revision、低置信度、语言等价、超时/异常及所有失效事件。
- SC-005 的 ≥95% 正确方向比例以预先固定的正文充分、元数据缺失/错误且目标不等价样本为分母；不能按实际是否发出请求再筛样本。
- 验收失败后不得继续用同一冻结集合优化参数；保留失败记录，按未暴露的新独立来源建立后续验收版本，并重新完成冻结。客观数据错误需记录依据和语料版本，不能借机改写预期或删除难样本。

## 性能与证据

首次检测使用至少 40 次独立进程/运行时初始化，重复检测使用至少 40 次同运行时调用，分别计算 p95；实际步骤单独计时并计算 p99，计时包括扫描、抽样、分类、聚合与调度等待，不包括字幕提取。新进程还单列模型导入时间，避免漏报完整模型成本。

Node 自动化和指定 IINA 宿主环境分别记录设备、架构、系统/宿主版本、语料与配置哈希、包哈希、分位数和最慢值；Node 结果不代替宿主结论。20,000 cue 上限场景验证有界处理、期限和播放连续性，合成压力输入可使用，但不计自然语言准确率。

证据只包含样本 ID、计数、真值/实测语言身份、时长、状态和安全结论；不包含字幕正文、译文、媒体路径、原始标签、凭据或 Provider 请求。正式宿主证据未采集前保持未验收。

## 本地验收工具接口

新增 `scripts/language-detection-validation.mjs`，只作为开发工具，不进入安装包：

- `serve --port 8765`：仅监听 `127.0.0.1`，提供 OpenAI-compatible `/v1/models`、`/v1/chat/completions` 和只含计数的 `/metrics`。模型 ID 为 `validation-model`，无需凭据；按生产 ID wire 返回确定性测试译文，区分连接测试与实际翻译调用，不保存或打印请求正文。
- `host-metrics`：从标准输入读取粘贴的宿主安全计时记录，只接受约定字段，输出样本数、首次/重复 p95、步骤 p99、最慢值及是否满足性能门禁；忽略其他日志，不回显输入，不足以形成有效统计时报告未完成。

协调器通过注入的计时接收器提供真实步骤时长、总时长、首次/重复类别与最终状态；Main 仅将这些安全指标写入现有会话 Log Viewer，不写候选、语言、正文、内容哈希或身份。相同正式包检测代码用于自动化和宿主测量。报告中的样本 ID 由开发者按操作顺序关联，不通过生产诊断输出媒体标识。

最小媒体与字幕对应表纳入 `tests/fixtures/languages/`，复用项目已有最小媒体的生成方式并记录可重建命令。本地模拟回复只证明翻译流程，不作为语言真值或译文质量证据。

## 失败归因与候选修复

| 已确认的问题 | 证据与当前处理 |
| ------------ | -------------- |
| 短行证据被丢弃 | `acceptance-zh-19` 的采样正文有 50 个字母，基线仍返回 `unsupported`。franc 默认 10 码元入口与逐行文字/多样性门槛叠加，丢失短中文行。分类入口改用 `minLength: 1`，可靠性继续由实际字母、候选、覆盖率及轨道证据约束。 |
| 宏语言得分与模型错配 | 基线按宏语言取最高分，却可能以最后一个成员的模型检查覆盖率。当前把最高分与其模型代码一起保留；新增回归覆盖成员顺序不同的输入。 |
| 短局部分差覆盖片段上下文 | 基线俄语、丹麦语等样本的整体候选正确，局部权重却转向其他语言。当前要求独立局部证据同时具备文字量及分差，弱局部片段结合上下文竞争。 |
| 上下文长度与分差门槛不一致 | 依赖长片段分数时仍按局部行长度选择门槛，会丢弃后段英文证据。当前按实际提供分数的证据长度选择门槛；长样本在边界允许时使用四个采样区域作为上下文。单次分类仍 ≤2048 码元，总样本仍 ≤4096。 |

## 固定解释

- `加族语` 固定为 `Ga / gaa`，不得改为 Gayo。
- `苗语` 固定为 `Hmong / hmn`。
- `库尔德语` 固定为通用 `Kurdish / ku`，不替换为 `ckb` 或 `kmr`。
- `挪威语` 固定为通用 `Norwegian / no`。
- `菲律宾语` 固定为 `Filipino / fil`，不写入 `tl`。
- `Kri` 固定为 `Krio / kri`。
- `zh-Hans`、`zh-Hant`、`pt` 与 `pt-PT` 是四个独立偏好和缓存身份。
- `iw`、`in`、`ji` 只可在 source 规范化入口分别兼容为 `he`、`id`、`yi`；目标目录永远不输出旧别名。

所有目录项必须能生成非空 Provider label，格式为 `<English name> [<id>]`。目录与传递契约只保证身份、请求表达和恢复正确，不承诺任意用户模型对全部语言的翻译质量。

# 功能规格：字幕语言自动识别、目标语言扩展与偏好持久化

**功能标识**：`007-auto-language-support`

**创建日期**：2026-08-16

**状态**：已完成

**输入**：移除手动指定字幕语言的配置，由 SubTandem 自动识别字幕语言；将 `Mother Language` 改为 `Target Language`，扩展目标语言选项，并确保用户选中后自动保存的目标语言在 IINA 完整退出并重启后仍然有效。

## Clarifications

### Session 2026-08-18

- Q: 用户选择新目标语言后，何时应影响当前播放会话的翻译？ → A: 选中后立即进入自动保存，仅在保存成功后立即生效；旧目标语言的在途任务与缓存立即失效，保存失败时恢复并继续使用原目标语言。

## 用户场景与测试

### 用户故事 1：无需配置即可识别字幕语言（P1）

用户选择可读取的外挂字幕后，无需知道或填写语言标签，SubTandem 即可识别主要字幕语言，并以识别结果决定是否翻译以及翻译方向。

**优先原因**：移除源语言配置负担是本次调整的核心价值，也是开始翻译的前置条件。

**独立测试**：清除既有语言偏好，依次播放具有语言元数据、没有语言元数据以及元数据与正文不一致的字幕，确认界面没有手动字幕语言配置，翻译请求均使用字幕正文识别出的语言。

**验收场景**：

1. **假如** 字幕正文足以判断语言，**当** 用户选择该字幕并启用翻译，**那么** 系统自动识别主要语言并开始符合当前目标语言的翻译流程，不要求用户确认源语言。
2. **假如** 字幕轨带有语言元数据，**当** 系统处理字幕，**那么** 正文识别仍作为翻译方向的依据，错误或缺失的轨道元数据不会要求用户手动修正。
3. **假如** 用户从旧版本升级且保存过手动字幕语言，**当** 新版本开始处理字幕，**那么** 旧值不再影响识别结果，界面也不再提供该配置项。
4. **假如** 识别出的字幕语言与目标语言等价，**当** 翻译门控执行，**那么** 不向翻译服务发送字幕正文，并向用户显示无需翻译的状态。

---

### 用户故事 2：保存并恢复目标语言（P2）

用户在 `Languages` 区域通过 `Target Language` 选择希望生成的译文语言；不同于已提交值的选择会立即且只发起一次保存，并可在关闭 Sidebar、完整退出 IINA 或重启 IINA 后继续使用最近一次成功保存的选择。

**优先原因**：目标语言决定用户最终看到的译文；只有保存结果能够跨 IINA 会话恢复，用户的选择才不会在每次启动后回退并造成错误翻译方向。

**独立测试**：打开目标语言选择器并核对附录 A 的语言与唯一性；分别选择列表首项、中间项、末项以及两个中文和两个葡萄牙语变体，确认每次选择只发起一次保存，完整退出并重启 IINA 后恢复最近保存的选择且后续翻译使用对应语言。

**验收场景**：

1. **假如** 用户打开 `Languages` 区域，**当** 查看语言控件，**那么** 唯一可配置的语言字段标记为 `Target Language`，且不存在 `Mother Language` 或手动字幕语言字段。
2. **假如** 用户展开目标语言列表，**当** 浏览全部选项，**那么** 附录 A 的每种语言恰好出现一次，界面名称与语言身份一一对应。
3. **假如** 用户选择一个受支持的非默认目标语言，**当** 自动保存成功、完整退出 IINA、重新启动并打开 Sidebar，**那么** 控件恢复该语言，且后续译文以该语言为目标，不得回退到默认语言。
4. **假如** 用户先后保存两个不同的目标语言，**当** 在最后一次保存后重启 IINA，**那么** 系统恢复最近一次成功保存的语言。
5. **假如** 用户分别选择中文简体、中文繁体、葡萄牙语和葡萄牙语（葡萄牙），**当** 逐项保存、重启 IINA 并执行翻译，**那么** 四个选项保持可区分，不会被错误合并为同一选择。
6. **假如** 用户没有保存过目标语言，或已保存值不再受支持，**当** 启动 IINA 并打开 Sidebar，**那么** 系统选择中文（简体）作为默认语言；有效的已保存值不得被该默认值覆盖。

### 用户故事 3：识别失败时保持播放安全（P3）

当字幕样本过短、混合语言过多或无法可靠判断主要语言时，用户仍可正常观看原视频和原字幕，并能理解当前没有发送字幕或生成译文。

**优先原因**：自动识别取代人工兜底后，失败行为必须明确且不得造成错误翻译或不必要的字幕外发。

**独立测试**：使用空白、仅符号、极短、混合语言和不受支持语言的字幕，确认播放不中断、没有错误方向的翻译请求，并显示可理解的识别失败状态。

**验收场景**：

1. **假如** 字幕为空白、只有标点或可用文字不足，**当** 自动识别无法得出可靠结果，**那么** 系统不发送字幕正文、不阻塞播放，并显示无法识别字幕语言的状态。
2. **假如** 字幕包含多种语言，**当** 其中一种语言可被判定为主要语言，**那么** 系统按主要语言处理整条字幕源，并在字幕源变化后重新识别。
3. **假如** 自动识别的语言不受当前翻译流程支持，**当** 用户启用翻译，**那么** 系统不发送错误语言方向的请求，并显示当前字幕语言不受支持。
4. **假如** 用户换轨、换片或字幕内容发生变化，**当** 新字幕源生效，**那么** 旧识别结果立即失效，迟到结果不得影响新会话。

### 边界情况

- 字幕的语言元数据缺失、无效或与正文不一致时，以当前字幕正文的自动识别结果为准。
- 字幕开头只有片名、专有名词、数字或少量文本时，系统可等待足够样本；在可靠识别前不得发送翻译请求。
- 双语或多语字幕没有单一主要语言时，按无法可靠识别处理，不推测翻译方向。
- 自动识别结果与目标语言只有地区或书写系统差异时，必须保留用户显式选择的变体；只有语言身份等价时才跳过翻译。
- 保存过旧手动字幕语言偏好的用户升级后，该偏好不得继续影响任何会话，也不得在界面中重新出现。
- 目标语言偏好缺失或已不在附录 A 时，使用中文（简体）作为默认选择。
- 已存在有效目标语言偏好时，启动 IINA、打开或重复打开 Sidebar、切换播放器窗口均不得用默认语言覆盖该偏好。
- 用户更改目标语言时，不同于已提交值的选择立即发起一次保存；等待结果期间选择器不可重复操作。保存成功后，新值立即影响当前会话并成为下次启动的恢复值，旧目标语言的在途任务与缓存立即失效；保存失败、取消或异常时恢复已提交值且不改变当前有效语言与既有偏好。

## 需求

### 功能需求

- **FR-001**：产品 MUST 从 `Languages` 区域移除手动字幕语言输入及其保存操作，并 MUST NOT 要求用户输入或确认字幕语言。
- **FR-002**：系统 MUST 根据当前所选外挂字幕的正文自动识别主要语言；字幕轨元数据 MAY 用于辅助判断，但 MUST NOT 覆盖冲突的正文识别结果。
- **FR-003**：系统 MUST 在获得可靠的自动识别结果之前阻止字幕正文发送至翻译服务；识别失败 MUST NOT 阻塞视频或原字幕播放。
- **FR-004**：自动识别结果 MUST 绑定当前播放器窗口与字幕源；换轨、换片、字幕内容变化、禁用或关闭 MUST 使旧结果及相关迟到工作失效。
- **FR-005**：识别出的语言与目标语言等价时，系统 MUST 跳过翻译服务调用；用户显式选择的地区或书写系统变体 MUST 保持其独立身份。
- **FR-006**：`Mother Language` 标签 MUST 改为 `Target Language`，该控件 MUST 成为 `Languages` 区域唯一的语言配置项。
- **FR-007**：目标语言选择器 MUST 恰好提供附录 A 的 156 个选项；每个界面名称 MUST 映射到唯一、稳定且可被翻译流程使用的语言身份。
- **FR-008**：用户选择不同于已提交值的目标语言后，系统 MUST 立即且只发起一次保存，并在等待期间阻止重复选择；保存成功后 MUST 立即用于当前会话并使旧目标语言的在途任务与缓存失效，保存失败、取消或异常时 MUST 恢复原目标语言且不得改变既有偏好。系统 MUST 在关闭 Sidebar、完整退出 IINA 或重启 IINA 后恢复最近一次成功保存的选择；仅在首次使用、偏好缺失或值不再受支持时 MUST 默认选择中文（简体）。
- **FR-009**：中文（简体）与中文（繁体）、葡萄牙语与葡萄牙语（葡萄牙）MUST 分别保持为可独立选择、保存和传递的目标语言。
- **FR-010**：升级后，既有手动字幕语言及其模式偏好 MUST 不再参与语言识别、翻译门控、缓存身份或请求方向，并 MUST 从当前产品状态中移除。
- **FR-011**：自动识别失败、语言不受支持以及字幕与目标语言相同 MUST 向用户呈现彼此可区分的状态，且 MUST NOT 暴露字幕正文或服务内部错误。
- **FR-012**：语言识别 MUST 在字幕正文发送到用户选择的翻译服务之前完成；本功能 MUST NOT 新增字幕正文的网络目的地、跨会话持久化或诊断输出。
- **FR-013**：除语言识别与目标语言选择外，现有外挂 SRT/ASS 读取、有限前瞻、会话缓存、Provider 选择、第二字幕显示和多窗口隔离边界 MUST 保持不变。
- **FR-014**：IINA 或 Sidebar 初始化完成后 MUST 以有效的目标语言偏好作为当前选择，MUST NOT 以默认值覆盖该偏好；连续保存多个选择时，最近一次成功保存的选择 MUST 成为后续会话的恢复值。

### 关键实体

- **字幕语言识别结果**：当前播放器窗口和字幕源的主要语言、可靠状态及生命周期身份；字幕源变化后立即失效，不跨会话持久化。
- **目标语言选项**：面向用户的显示名称与稳定语言身份的唯一映射，可被选择、保存并用于确定译文语言。
- **目标语言偏好**：用户最近一次通过选择器自动保存成功的目标语言身份；跨 Sidebar 与 IINA 会话保留，但不包含字幕正文或源语言推断。

### 范围边界

**范围内**：移除手动字幕语言配置和旧偏好影响、基于外挂字幕正文的自动语言识别、识别状态与安全门控、`Target Language` 标签、附录 A 的完整选项、选中即保存目标语言、跨 Sidebar 与 IINA 重启恢复目标语言、升级行为及相关自动化与人工验收。

**范围外**：音频语种识别、音频转写、内嵌或图形字幕提取、逐条字幕的多语言分别翻译、用户自定义语言项、界面整体本地化、扩大字幕外发或持久化范围。

## 成功标准

### 可衡量结果

- **SC-001**：对覆盖附录 A 中至少 20 个不同文字或语系、每种不少于 20 条自然字幕的验收样本，主要语言识别准确率达到 95% 以上；不可靠样本被错误判为可靠语言的比例不高于 1%。
- **SC-002**：对语言元数据缺失或错误但正文样本充分的字幕，至少 95% 可在用户无需任何源语言操作的情况下进入正确翻译方向。
- **SC-003**：语言无法可靠识别、字幕与目标语言等价及语言不受支持的测试中，错误方向的翻译服务调用次数均为 0，视频播放中断次数为 0。
- **SC-004**：目标语言选择器包含附录 A 的全部 156 个选项，缺失、重复和错误语言映射均为 0；所有选项均可成功保存，并在后续会话中恢复。
- **SC-005**：旧版本升级测试中，已保存的手动字幕语言影响新识别结果或翻译方向的次数为 0，界面中残留的手动字幕语言配置入口为 0。
- **SC-006**：开发者按首次使用验收步骤操作时，可在 30 秒内找到 `Target Language`、选择任一语言并保存，且无需查找或填写字幕源语言。
- **SC-007**：换轨、换片、字幕变化与多窗口并发测试中，旧识别结果或迟到工作写入错误会话的次数为 0；既有播放安全和字幕内容最小外发检查全部保持通过。
- **SC-008**：对列表首项、中间项、末项、两个中文选项、两个葡萄牙语选项及任一其他非默认选项执行保存与 IINA 重启验收时，目标语言恢复成功率为 100%，回退到默认语言的次数为 0；连续保存两个不同选择后恢复旧值的次数为 0。

## 假设

- 自动识别以当前所选、可读取的外挂 SRT 或 ASS 字幕正文为输入；本功能不改变外挂字幕的加载与选择方式。
- “自动识别字幕语言”指识别字幕正文的主要语言，不将 IINA 轨道语言标签视为唯一依据。
- 混合语言字幕按单一主要语言处理；无法可靠确定主要语言时停止翻译并显示状态，不恢复人工输入。
- 用户提供的语言集合和顺序是目标语言列表的验收基准；现有 Sidebar 继续使用英文界面名称，附录 A 使用中文名称描述对应语言，不引入整体界面本地化。
- 用户输入中的 `Kri` 按 Krio 语言处理；计划阶段需固定其稳定语言身份与英文界面名称。
- 自动识别能力与现有字幕内容保持同一会话级生命周期，不将源语言或字幕样本写入跨会话偏好。
- 目标语言偏好属于同一用户安装下的全局配置，不按播放器窗口、媒体文件或翻译 Provider 分别保存。
- 只有自动保存成功的选择需要跨会话保留；等待中或失败的候选不得改变当前已提交值。
- 本功能依赖现有 `Languages` 设置入口和 IINA 正常退出、重新启动流程，不改变其他配置项的保存语义。

# 功能规格：内嵌字幕翻译

**功能标识**：`008-embedded-subtitle-translation`

**创建日期**：2026-08-16

**状态**：草案

**输入**：为 SubTandem 增加对本地媒体中文本型内嵌软字幕的翻译支持，使用户无需另行寻找或导出外挂字幕。

## 澄清记录

### 2026-08-16

- Q: 字幕准备达到 15 秒超时后，系统应如何处理仍在运行的本次准备工作？ → A: 本次尝试失效；丢弃迟到结果；用户手动重试

## 用户场景与测试

### 用户故事 1：直接翻译本地媒体的内嵌文本字幕（P1）

用户播放本地媒体并选中其中一条文本型内嵌字幕后，可以像使用外挂字幕一样启用翻译；原字幕继续作为主字幕播放，译文显示在第二字幕轨，用户无需预先导出字幕或安装额外工具。

**优先原因**：这是本功能的核心价值，直接解决只有内嵌字幕时无法使用 SubTandem 的问题。

**独立测试**：分别播放包含 Matroska SubRip、Matroska ASS/SSA 和 MOV/MP4 `mov_text` 内嵌字幕的本地媒体，选中目标字幕并启用翻译，确认当前播放位置附近的正确字幕被发送给已选 Profile revision 对应的 Provider，原字幕持续显示，译文出现在第二字幕轨，且系统未要求用户准备外挂文件或安装其他软件。

**验收场景**：

1. **假如** 本地媒体包含受支持的文本型内嵌字幕且用户已将其选为主字幕，**当** 用户启用 SubTandem 翻译，**那么** 系统自动准备该字幕并按当前播放位置开始翻译，无需用户执行字幕导出或路径选择。
2. **假如** 媒体包含多条内嵌文本字幕，**当** 用户选择其中一条，**那么** 只有被选字幕的文本进入当前翻译流程，语言、标题或排列相近的其他字幕不会被误用。
3. **假如** 内嵌字幕已可用于翻译，**当** 播放继续或用户跳转进度，**那么** 系统仍只翻译当前位置附近的有限字幕，原字幕和视频不因准备或翻译延迟而暂停。
4. **假如** 用户在受支持环境安装正式插件包，**当** 首次翻译内嵌文本字幕，**那么** 功能可以直接使用，不要求另行下载、配置或定位辅助程序。

---

### 用户故事 2：切换字幕源时保持结果正确（P2）

用户可以在同一媒体的多条内嵌字幕之间切换，也可以改选外挂字幕；SubTandem 始终以当前窗口、当前媒体和当前所选主字幕为准，不让旧字幕的准备、翻译或显示结果污染新选择。

**优先原因**：影视文件常包含多语言或评论字幕，正确的选轨和会话隔离是功能可信赖的前提。

**独立测试**：在含两条以上内嵌文本字幕和一条外挂字幕的媒体中连续换轨、跳转和开关翻译，并在两个播放器窗口并行操作，确认每个窗口只显示所属当前字幕源的译文，外挂字幕既有行为不变。

**验收场景**：

1. **假如** 一条内嵌字幕正在准备或翻译，**当** 用户改选另一条字幕，**那么** 旧字幕相关状态立即失效，迟到的准备、请求或结果不得进入新字幕会话。
2. **假如** 用户从内嵌字幕切换为受支持的外挂字幕，**当** 翻译继续，**那么** 系统恢复现有外挂字幕流程，不要求重启播放或插件。
3. **假如** 两个播放器窗口分别选择不同的内嵌字幕，**当** 两边同时准备、播放和翻译，**那么** 字幕、状态、缓存、临时数据和译文保持窗口隔离。
4. **假如** 用户换片、停止播放、关闭窗口或禁用翻译，**当** 旧会话仍有未完成工作，**那么** 该工作不得改变后续会话的字幕或状态。

---

### 用户故事 3：不受支持或准备失败时安全观看（P3）

当用户选择图形字幕、硬字幕、远程媒体中的内嵌字幕，或文本字幕无法读取时，SubTandem 明确说明当前不能翻译的原因，同时保持视频和原字幕正常播放，不进行错误翻译或无意义的内容外发。

**优先原因**：内嵌字幕类型复杂，失败边界必须可理解且符合播放优先和数据最小化原则。

**独立测试**：分别选择 PGS、VobSub、损坏的文本字幕、空字幕以及远程媒体字幕，模拟准备超时和失败，确认各情况显示可区分状态、翻译 Provider 未收到无效字幕、播放未被中断，结束会话后没有遗留字幕临时数据。

**验收场景**：

1. **假如** 用户选择图形型内嵌字幕，**当** 启用翻译，**那么** 系统显示该字幕类型暂不支持且不会尝试文字识别、发送字幕或阻塞播放。
2. **假如** 字幕文字永久烧录在画面中而不存在可选字幕轨，**当** 用户启用翻译，**那么** 系统继续按“无可用字幕源”处理，不分析视频画面或音频。
3. **假如** 用户播放远程媒体并选择其内嵌字幕，**当** 启用翻译，**那么** 系统显示远程内嵌字幕暂不支持，不为提取字幕而重复下载媒体。
4. **假如** 受支持的内嵌文本字幕为空、损坏、无法读取或准备超时，**当** 准备失败，**那么** 系统显示可重试的失败状态，不发送错误字幕、不隐藏原字幕、不停止视频。

### 边界情况

- 多条字幕具有相同语言、标题或未知元数据时，系统仍以用户实际选中的轨道为唯一来源，不根据相似元数据猜测另一条轨道。
- 字幕轨没有有效文字、只有样式信息、时间码无效或字符无法解码时，按准备失败处理；不得用其他轨道静默替代。
- 用户在字幕准备期间跳转播放位置时，准备成功后从最新位置附近开始翻译，不补发已经离开的整段字幕。
- 极大媒体或字幕条目很多时，准备过程不得暂停、拖慢或接管播放；超过允许等待时间后必须显示失败状态并允许用户重试。
- 会话在准备完成前结束时，迟到结果不得创建第二字幕轨或留下跨会话临时数据；异常中断产生的遗留数据必须在下次使用前清理。
- 同一媒体同时含外挂字幕、文本型内嵌字幕和图形型内嵌字幕时，每次换轨都按当前所选来源重新判定支持状态。
- 内嵌 ASS/SSA 的样式、定位或字体附件不要求复制到译文；对白文本、顺序和有效显示时间必须足以维持现有双语观看体验。

## 需求

### 功能需求

- **FR-001**：系统 MUST 将当前所选主字幕识别为外挂字幕、文本型内嵌字幕或不受支持的字幕源，并 MUST 只处理当前窗口与媒体中用户实际选中的轨道。
- **FR-002**：系统 MUST 支持本地 Matroska 媒体中的 SubRip、ASS 和 SSA 内嵌字幕，以及本地 MOV/MP4 媒体中的 `mov_text` 内嵌字幕；有效对白文字、顺序及显示时间 MUST 可进入现有翻译体验。其他 codec 与容器组合不属于首版支持范围。
- **FR-003**：用户 MUST 能直接翻译受支持的内嵌字幕，且 MUST NOT 被要求手动导出字幕、选择中间文件或另行安装辅助程序。
- **FR-004**：内嵌字幕准备完成后，系统 MUST 复用本功能验收时产品生效的统一字幕语言决策、有限前瞻、批量翻译、会话缓存、Provider 选择和第二字幕显示行为，不得改为整片预翻译。
- **FR-005**：内嵌字幕的准备和翻译 MUST 与视频播放解耦；等待、失败、重试或取消 MUST NOT 暂停视频、隐藏原字幕或阻止用户跳转。
- **FR-006**：系统 MUST 以窗口、媒体和所选字幕源共同界定内嵌字幕会话；换轨、换片、停止播放、禁用翻译或关闭窗口 MUST 使旧会话及其迟到工作失效。
- **FR-007**：多窗口并行播放时，每个窗口的字幕源、准备状态、临时数据、翻译缓存和第二字幕轨 MUST 相互隔离。
- **FR-008**：系统 MUST 保持用户选中的原字幕为主字幕，并 MUST 仅将属于当前会话的译文发布为第二字幕；内嵌字幕支持不得改变这一显示关系。
- **FR-009**：图形型字幕（包括 PGS、VobSub 和 DVB 字幕）MUST 明确标记为暂不支持；系统 MUST NOT 对其执行文字识别、将图形数据发送给 Provider 或改用其他轨道。
- **FR-010**：烧录在视频画面中的硬字幕和音频转写 MUST 保持在本功能范围外，系统 MUST NOT 为本功能分析视频帧或音频内容。
- **FR-011**：远程媒体中的内嵌字幕 MUST 在首版明确标记为暂不支持；系统 MUST NOT 为准备字幕而新增媒体下载、远程鉴权或网络目的地。
- **FR-012**：系统 MUST 向用户区分“正在准备”“字幕类型不支持”“远程媒体不支持”“字幕为空或无法读取”“准备超时或失败”等状态；字幕准备持续 15 秒仍未可用时 MUST 判定为超时、立即使本次准备尝试失效并丢弃其迟到结果，且 MUST 仅在用户明确重试时创建新的准备尝试，同时提供重新选择字幕的可行路径。
- **FR-013**：只有当前播放位置附近的必要字幕文字、既有不透明字幕标识和有限上下文 MAY 发送给用户当前明确选择且 revision 仍有效的 Profile 所配置的 Provider；Profile 选择或 revision 变化 MUST 使旧请求及其迟到结果失效。视频、音频、媒体文件、完整媒体路径和完整字幕轨 MUST NOT 发送给 Provider。
- **FR-014**：准备过程中产生的字幕数据和中间文件 MUST 仅在所属会话内保留，并 MUST 在换轨、换片、停止播放、禁用、关闭窗口或插件退出后清理；异常中断产生的遗留数据 MUST 在下次使用前清理，且 MUST NOT 建立跨会话字幕或译文缓存。
- **FR-015**：凭据、字幕正文、译文、完整媒体路径和 Provider 请求内容 MUST NOT 出现在日志、诊断信息或安装包中。
- **FR-016**：正式插件包 MUST 自带完成受支持内嵌字幕翻译所需的运行组件及合规声明，并 MUST 在当前声明支持的 macOS、处理器架构和 IINA 版本上无需外部依赖即可工作。
- **FR-017**：插件对本地媒体文件及临时数据的访问范围、用途和保留周期 MUST 在安装权限说明与用户文档中准确披露。
- **FR-018**：现有外挂 SRT/ASS 字幕的读取、翻译、错误处理、隐私边界和多窗口行为 MUST 保持不变，并 MUST 与内嵌字幕使用一致的用户控制方式。

### 关键实体

- **字幕源**：当前窗口和媒体中用户选择的主字幕，具有外挂、内嵌文本或不受支持三类身份，并关联唯一的会话生命周期。
- **内嵌字幕轨**：媒体容器中的一条可选字幕，包含用户可见的轨道身份、字幕类型、语言或标题元数据以及实际定时内容；相似元数据不能替代真实选轨身份。
- **字幕准备会话**：从当前内嵌字幕获得可翻译定时文本的短期活动，具有准备中、可用、不支持、失败、超时或已失效状态，只属于一个窗口、媒体和字幕源。
- **定时字幕集合**：准备成功后供现有翻译流程使用的对白文字、顺序和显示时间；仅在当前会话存在，不代表持久化导出文件。

### 范围边界

**范围内**：本地 Matroska 媒体中的 SubRip、ASS 和 SSA，以及本地 MOV/MP4 媒体中的 `mov_text` 文本型内嵌软字幕；正确选轨；异步准备、失败与重试状态；换轨、换片和多窗口隔离；临时数据清理；无需外部依赖的正式插件包；外挂字幕回归；权限、隐私和合规披露。

**范围外**：PGS、VobSub、DVB 等图形字幕的文字识别；烧录硬字幕识别；音频转写；远程或受鉴权媒体的内嵌字幕准备；整片预翻译；字幕导出；跨会话字幕或译文缓存；新增翻译 Provider。

## 成功标准

### 可衡量结果

- **SC-001**：在至少 30 个覆盖 Matroska SubRip、Matroska ASS/SSA、MOV/MP4 `mov_text`、多字幕轨和不同语言的本地验收样本中，用户实际选中字幕与进入翻译流程的字幕一致率为 100%，有效对白与时间顺序的完整率不低于 99.9%。
- **SC-002**：对时长不超过 4 小时、媒体大小不超过 20 GB、字幕不超过 20,000 条的受支持本地样本，95% 在启用翻译后 5 秒内进入可翻译状态；准备期间的视频播放中断次数为 0。
- **SC-003**：在换轨、换片、跳转、禁用、关闭窗口和双窗口并发各不少于 20 次的验收中，旧字幕、迟到结果、缓存或第二字幕轨进入错误会话的次数为 0。
- **SC-004**：对图形字幕、硬字幕、远程媒体、空字幕、损坏字幕和准备超时样本，不符合范围的字幕内容被发送给 Provider 的次数为 0，视频或原字幕被中断的次数为 0，所有情况均显示与原因匹配的状态。
- **SC-005**：在 Apple Silicon 与 Intel 正式包环境中，IINA 1.4.0 基线和 IINA 1.4.4 固定发布版组成的四个架构/宿主验收组合，其安装成功率和首次内嵌字幕任务完成率均为 100%；每项证据 MUST 记录实际 macOS 版本和包 SHA-256，验收环境无需预装额外字幕工具。
- **SC-006**：在全部会话结束与清理场景中，跨会话遗留的字幕正文、译文或中间文件数量为 0；日志和诊断样本中出现凭据、字幕正文、译文、完整媒体路径或 Provider 请求内容的次数为 0。
- **SC-007**：现有外挂 SRT/ASS 自动化与人工验收样本通过率为 100%，内嵌字幕功能不会增加其操作步骤、外发范围或播放中断。
- **SC-008**：开发者本人使用正式插件包完成一次可用性验收：不查阅额外操作说明，在 30 秒内为本地媒体选中内嵌文本字幕并开始翻译；遇到不支持的字幕时，仅依据状态说明选择可行下一步；两项均须通过。

## 假设

- “内嵌字幕”在首版指封装于本地媒体容器、可作为独立轨道选择的软字幕；画面中的硬字幕不属于同一类输入。
- Matroska SubRip、Matroska ASS/SSA 和 MOV/MP4 `mov_text` 覆盖首版承诺的文本型内嵌字幕；其他 codec 或容器组合只有在新的有界变更中补充明确兼容矩阵和验收样本后才可加入。
- 用户继续通过 IINA 选择主字幕并通过 SubTandem 开关翻译；本功能不新增独立的字幕轨选择器。
- IINA 能向插件提供当前窗口、当前本地媒体和当前所选字幕轨的必要身份信息，并允许插件读取用户已打开的本地媒体。
- 本功能复用最终验收时产品生效的统一字幕语言决策，不引入另一套手动源语言配置；选轨、字幕准备、会话隔离、失败处理和打包等工作不以任何特定功能完整交付为前置。
- Provider 已由用户测试并明确选择；字幕准备不会改变既有授权关系、计费责任或网络路线。
- 正式插件包可以增加完成本功能所必需且许可证兼容的运行组件，但仍须保持发布产物可重建、最小且包含必要第三方声明。

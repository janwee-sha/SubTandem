# 数据模型：覆盖层译文渲染

本功能不新增持久化模型。以下状态全部属于单个 Main 播放窗口，并随现有播放会话失效而清理。

## 当前有效译文

表示当前播放位置可显示的一条已验证译文。

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `cueId` | 源 cue 的稳定标识 | 属于当前 session fingerprint |
| `sourceIndex` | cue 在当前源中的顺序 | 合并显示时保持升序 |
| `startMs` / `endMs` | 有效时间区间 | 仅在 `startMs <= positionMs < endMs` 时有效；零时长不显示 |
| `text` | Provider 已验证的译文 | 非空；保留语义换行；不得包含占位或技术错误 |

选择器遍历当前源 cue 并查询当前会话译文缓存，不读取未来会话或其他窗口数据。多个 cue 同时有效时按源顺序输出，未来和过期译文均不进入显示帧。

## 译文显示帧

controller 交给覆盖层 sink 的不可变快照。

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `lines` | 当前有效译文文本列表 | 按源 cue 顺序；cue 内换行保留；空列表表示应清理 |
| `sessionFingerprint` | controller 用于提交前复核的会话身份 | 不进入 ASS、日志或适配器持久状态 |
| `positionMs` | 生成帧时的播放位置 | 只用于选择有效 cue，不传给 mpv |

显示帧不包含 SRT、轨道 ID、文件路径、Profile、Provider 请求或固定样式参数。

## 固定覆盖层样式

编译期常量，不是用户设置，也不持久化。

| 属性 | 值 |
| --- | --- |
| 逻辑画布 | `res_x=0`、`res_y=720` |
| 对齐 | 顶部居中、文本居中 |
| 字体大小 | `40`，随窗口高度等比缩放 |
| 字色 | 白色 |
| 可读性 | 黑色描边、无阴影 |
| 背景 | 透明 |
| 换行 | 保留语义换行并按安全宽度自动换行 |
| 超高内容 | 允许被窗口裁切；不主动截断、省略或额外缩字 |

## 覆盖层渲染状态

适配器仅保存避免重复命令所需的最小状态。

| 状态 | 字段 | 含义 |
| --- | --- | --- |
| `empty` | 无 | 当前没有已提交内容 |
| `visible` | `lastData` | 已向自有 overlay ID 提交的完整 ASS data |

### 状态转换

| 当前状态 | 输入 | 动作 | 下一状态 |
| --- | --- | --- | --- |
| `empty` | 非空且不同的 `lines` | 转义并发送 show | `visible` |
| `visible` | 内容不同的 `lines` | 对同一 ID 发送 replace | `visible` |
| `visible` | 相同内容 | 不发送命令 | `visible` |
| `visible` | 空帧或会话失效 | 对自有 ID 发送 `format=none` | `empty` |
| `empty` | 空帧或重复 clear | 不发送命令 | `empty` |
| 任意 | 命令同步抛错 | 保持原状态，报告无正文失败并允许重试 | 不变 |

IINA 的 `void` API 无法确认宿主是否真正渲染；“命令未抛错”只表示适配器可提交本地去重状态，正式宿主验收仍是交付门。

## 关系与生命周期

```text
播放会话身份 1 ── 1 当前播放位置
       │
       └── N 源 cue ── 0..1 当前会话译文
                         │
                         └── 当前有效译文集合 ── 1 显示帧
                                                    │
                                                    └── 1 逐窗口覆盖层渲染状态
```

- 会话先失效，再清理覆盖层；迟到结果因 fingerprint 不匹配而不能生成新帧。
- 每个窗口拥有独立 controller、缓存、sink、mpv port 和渲染状态。
- 覆盖层内容不写入文件，不跨会话复用，不进入 Global、Sidebar 或 preferences。

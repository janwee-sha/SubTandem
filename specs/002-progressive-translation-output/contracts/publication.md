# 第二字幕渐进发布契约

## 输入

controller 每接受至少一个新 cue 后，用当前会话全部有效译文渲染一个完整 SRT 快照并请求发布。

## 单飞合并

- 空闲时首个有效快照立即调用 `GeneratedTrackSink.swap`。
- 替换在途时不启动第二个 `swap`，只覆盖保存最新快照。
- 当前替换结束后，如最新快照仍属于当前会话则立即发布；否则丢弃。
- `whenIdle()` 只有翻译 pipeline 与发布协调器都空闲后才完成。

## 状态与错误

- 首个当前快照成功完成 `swap` 后，会话状态转为 `running`。
- `swap` 失败时状态转为 `partialFailure`，已验证翻译和缓存保持不变；后续新快照可再次发布。
- 生命周期在 `swap` 期间失效时，迟到完成不得改变状态，并清理该失效发布产生的插件自有轨道。

## 所有权

协调器每个 `PlaybackController` 独立存在。它只调用自身注入的 track sink，不触碰其他窗口或用户拥有的字幕轨。

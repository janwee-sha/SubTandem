# 研究结论：GPL 许可与首版合规发布

## 许可证表达

**决策**：使用标准 GPL v3 全文和 SPDX `GPL-3.0-only`。

**理由**：固定 SPDX 标识可被 GitHub 与包管理工具识别，且不会自动扩大到未来 GPL 版本。

## 随包声明

**决策**：`THIRD_PARTY_NOTICES.txt` 只披露实际进入安装包或与随包二进制静态链接的非系统组件。

**理由**：开发依赖不进入安装包，系统动态库也不是项目分发的第三方二进制；最小声明同时满足合规和最小产物原则。

## 发布身份

**决策**：v0.1.0 只允许由当前审计结果首次创建；发布器不提供同版本覆盖模式。

**理由**：不可覆盖的稳定版本使 tag、正文、资产与 SHA-256 保持可验证一致，并符合新仓库从首版开始的历史边界。

# 首版发布合规契约

## 输入

- 当前审计后的 v0.1.0 安装包、校验文件、锁定 FFmpeg 源码资产与英文发布正文。
- 当前触发 commit 和完整发布门禁结果。

## 前置条件

- 仓库与包元数据使用 `GPL-3.0-only`。
- 归档根包含与仓库一致的 `LICENSE` 与 `THIRD_PARTY_NOTICES.txt`。
- v0.1.0 tag 和 Release 尚不存在，或已存在且与当前审计身份完全一致。

## 输出

- `v0.1.0` tag 指向触发 commit。
- Release 公开、非 prerelease、Latest，正文等于审计后的英文说明。
- 安装包、校验文件和 FFmpeg 源码资产与审计摘要一致。
- 相同身份后续执行返回只读跳过；任一漂移失败且不得覆盖远端对象。

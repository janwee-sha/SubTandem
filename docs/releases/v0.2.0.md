# SubTandem v0.2.0

## New Features

- View and edit saved API keys in the Profile editor, masked by default, with **Show API key** and **Hide API key** controls. Saving an empty API key field now clears the saved key.

## Improvements

- Updated the empty Profile list styling.
- Removed the extra API key save confirmation beneath the Profile list.

## Bug Fixes

- Fixed startup Profile loading failures that blocked **New profile**.

## Upgrade and Compatibility Notes

- Upgrading from v0.1.9 preserves Profile settings and a valid enabled selection, but clears saved API keys. Re-enter and save keys for services that need them. Snapshots and other backups may still contain old keys; rotate those keys with your service.
- Saving or using a nonempty API key requires a Mac with Secure Enclave. Services that do not require an API key remain supported.
- Back up the complete `credentials.json`. Restoring saved API keys requires the original Mac, user account, and valid system keys, and is not guaranteed. Re-enter any key that cannot be recovered.

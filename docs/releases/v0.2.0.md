# SubTandem v0.2.0

## New Features

- Edit a saved API key directly in its Profile. The value is masked by default; use **Show API key** and **Hide API key** to inspect it without changing your input or selection. **Save** replaces the key with the current input, saving an empty field clears it, and **Cancel** discards unsaved edits. If the saved key cannot be read, you can enter a replacement or save the empty field to clear it; other Profiles remain unchanged.

## Improvements

- The empty Profile list now shows **No profiles yet.** centered in a rounded card. **New profile** remains available beside the section title, and cancelling your first draft returns to the empty list.
- Saving an API key no longer leaves an extra success message beneath the Profile list.

## Bug Fixes

- Opening an existing Profile now waits for its saved API key before automatically refreshing models. Manual refresh, **Test**, and **Save** are temporarily disabled during the read, preventing premature requests and accidental clearing of a key that has not loaded. Fields remain editable, and **Delete**, **Cancel**, and closing the drawer remain available. Profiles without a saved key and new drafts need no extra wait.
- An API key read that fails or does not finish within 15 seconds releases the editing controls. Late results no longer overwrite your input or affect another drawer; actual model refresh, Test, and Save failures still report their normal errors.
- If the Profile list cannot load at startup, SubTandem now opens an empty list with **New profile** available instead of asking you to restart IINA. Damaged configuration data can be replaced by saving a new Profile. Temporary access failures preserve valid saved Profiles, and a failed Save keeps your draft available for retry. A problem with one saved API key does not reset the list.

## Upgrade and Compatibility Notes

- Upgrading from the previous plaintext storage format preserves Profile settings and a valid enabled selection, but clears saved API keys. Open each Profile that needs a key, enter it again, and save. Services that do not require a key remain usable. Managed old copies are cleaned up, but snapshots and other backups may still contain old keys; rotate those keys with your service.
- Saving or using a nonempty API key requires a Mac with Secure Enclave. Newly saved keys remain available on the same Mac and user account after restarting IINA, restarting the Mac and signing in, or later plugin upgrades, without extra authorization, a master password, or biometric prompts.
- Back up the complete `credentials.json` with its recovery material. Restoring saved API keys requires the original Mac, user account, and valid system keys, and is not guaranteed. If a key cannot be recovered, enter and save a replacement in that Profile.

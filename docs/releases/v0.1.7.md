# SubTandem v0.1.7

## Bug Fixes

- Prevent IINA startup and playback sessions from stalling or crashing when subtitle preparation completes while the player is still waiting for a helper process.
- Keep sustained subtitle translation responsive without progressive memory, thread, or CPU growth that could eventually freeze IINA.
- Prevent repeated Profile switching during active translation from crashing IINA, while ensuring only the latest selected Profile can publish translation results.
- Restore Profile toggles and subtitle preparation automatically after background helpers exit while idle, without requiring an IINA restart. A failed Profile change now becomes retryable instead of leaving its controls disabled.

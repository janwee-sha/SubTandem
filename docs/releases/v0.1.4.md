# SubTandem v0.1.4

## New Features

- Translate readable short, romanized, mixed-language, and unknown-source subtitle tracks without waiting for local language detection. The selected translation service now determines the source language for each subtitle within the existing translation request.
- Keep already-target-language subtitles in the normal translation flow and require the selected service to return them character for character, preserving capitalization, spacing, punctuation, and line breaks.
- Show only actionable subtitle preparation, configuration, translation, and service status in the sidebar. The previous detected-language field and language-detection states have been removed.

## Upgrade and Compatibility Notes

- Short, unknown-source, mixed-language, and already-target-language text is still sent to the explicitly selected service when translation is enabled and may incur service charges.
- The selected model must be able to infer source languages, follow the exact target language or regional variant, return structured translations, and preserve already-target-language text exactly.

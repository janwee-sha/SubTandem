# SubTandem v0.1.9

## New Features

- Hover over a shortened name, service and model, or Endpoint line in a saved Profile to read its full text. A shortened line is also available in full when navigating the Profile with a keyboard or assistive technology; lines that fit do not show a duplicate hover hint.

## Improvements

- Collapsed Profile cards now show the name, service and model, and Endpoint. Expand a card to view its Network route and API key status.
- Session now shows readable subtitle format names and places Translated cues before Total cues, with plain counts for the current session.
- Model list refreshes stop using an outdated draft when its settings change or its editor closes. Late results no longer replace the current model list or Model ID.
- Test passed now requires a complete, nonblank result for the current test sample across OpenAI, Claude, DeepSeek, and Ollama. Empty or incomplete responses report an unsupported response instead of a successful Test.
- Editing an existing Profile's Endpoint, Network route, model, name, or other settings keeps its saved API key available for Test and model refresh, including before saving the changes. Changing Service type does not reuse the previous service's API key.
- When a translation service stops because its output is too long, Test and Session report an unsupported response. An explicit refusal continues to show the refusal message.

## Bug Fixes

- Successful Profile activation now clears an outdated activation timeout instead of leaving an error beside an enabled switch.
- After translations succeed, Session clears outdated service errors and reflects the current translation state.

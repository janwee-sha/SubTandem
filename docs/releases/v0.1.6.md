# SubTandem v0.1.6

## New Features

- Test a new or edited translation profile before saving it. Test uses the service, endpoint, model, network route, and key currently shown in the form, reports the result inside that form, and never saves or enables the profile or sends subtitle text.

## Improvements

- Manage profiles in a compact grouped list with one expandable editor. Saved profiles start collapsed, `New profile` opens a form at the top, switching or cancelling discards unsaved input, and a successful save returns to the updated summary.
- Keep profile actions attached to the expanded editor: Test and its feedback use the first row, while Delete, Cancel, and Save use the second. Profile summaries no longer show connection-test status.
- Start every new profile with `Connect directly` selected while preserving the route of existing profiles and any route already chosen in the current draft.

# SubTandem v0.1.3

## New Features

- Customize SubTandem's translated subtitle text from the existing Subtitle section. Font color, size, family, bold, italic, border color, border width, and background color update the current translated subtitle immediately without changing its content, timing, horizontal alignment, or saved position.
- Choose Font, Border, and Background colors from a compact palette, including transparency, or open the macOS system color panel for precise color and alpha adjustments. Each picker changes only its originating field, and closing it without a change preserves the previous value.
- Search and preview installed font families in a dedicated picker. Cancelling preserves the current font; if a saved font becomes unavailable, SubTandem temporarily uses the system font and automatically restores the selected family when it becomes available again.
- Reuse one saved subtitle style across media, playback windows, and IINA sessions. Concurrent windows merge edits to different fields, while the last valid edit wins for the same field; a failed save restores the last confirmed complete style without interrupting playback.

## Upgrade and Compatibility Notes

- Text style settings affect only subtitles rendered by SubTandem. They do not modify IINA's original subtitle track, source subtitle files, translation timing, or the existing Position preference.
- Existing installations start with white system text at Size 40, a black Border at Width 3, and a transparent Background. These mapped defaults preserve the previous Size 29 and Border Width 2 rendering baseline.

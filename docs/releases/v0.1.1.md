# SubTandem v0.1.1

## New Features

- Add DeepSeek as a dedicated translation service alongside OpenAI and Ollama, with its official API root as the default and support for discovered or exact custom model IDs.
- Create, test, select, edit, and delete independent DeepSeek profiles using the existing profile workflow and network route options.

## Improvements

- Request structured DeepSeek translations without thinking output, and reject incomplete or mismatched responses instead of displaying partial translations.
- Keep the current model selection available when DeepSeek model refreshes fail, while ignoring stale results after profile, endpoint, credential, route, or window changes.
- Keep playback and original subtitles responsive when DeepSeek authentication, quota, rate-limit, network, configuration, or response errors occur.

## Upgrade and Compatibility Notes

- Existing OpenAI and Ollama profiles, credentials, model discovery, selection, and translation behavior remain unchanged.
- DeepSeek requires a separately supplied API key and a valid model ID. Requests may incur charges under DeepSeek's terms.
- Only the profile you explicitly select receives subtitle text. A model-list refresh may contact the configured DeepSeek endpoint before selection without sending subtitle text.

# SubTandem v0.1.5

## New Features

- Enable, disable, or switch translation profiles using the toggle beside each profile name. At most one profile is enabled across all playback windows, and every window follows the last successfully confirmed change. Failed changes preserve the previous choice.
- Restore the enabled profile, or keep all profiles disabled, when opening another window or restarting IINA. If no global choice has been saved, all profiles start disabled. Saving changes to or deleting the enabled profile clears that choice; an unavailable or invalid saved profile is not automatically enabled.
- Keep profile activation separate from Translate: translation requires both an enabled profile and Translate to be on. Saving or testing a profile does not enable it.
- Click a profile's content area, or activate it with the keyboard, to open it for editing. The editing highlight updates immediately and stays distinct from its enabled toggle. Switching to another profile discards unsaved edits; using its toggle, Test, or Delete does not change which profile you are editing.

## Improvements

- Keep Test and Delete buttons aligned and the same size while testing or deleting, with only those two actions below each profile.
- Use a red Delete button and a macOS-style confirmation that identifies the profile and explains that its settings and saved key will be permanently removed. Cancel or Escape closes the confirmation without changing the profile.

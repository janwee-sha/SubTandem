# SubTandem v0.1.2

## New Features

- Add Claude as a dedicated translation service, listed after OpenAI, with independent profiles that can be created, tested, selected, edited, and deleted. New Claude profiles use Anthropic's official API root by default and also support compatible custom HTTP or HTTPS endpoints and existing network route options.
- Refresh models exposed by a Claude endpoint or enter an exact custom model ID. Unsupported or failed model discovery preserves the current model and custom input, while stale results cannot replace the active profile's choices.
- Translate subtitles through the Claude Messages format and display only complete, correctly matched results. Refused, truncated, empty, malformed, or mismatched responses are rejected without replacing the original subtitle or blocking playback.
- Keep Claude credentials write-only after saving and isolated to their profile. Model discovery before selection sends no subtitle text; only the explicitly selected profile revision receives nearby subtitle text for translation. Provider requests may incur charges under the service owner's terms.

## Upgrade and Compatibility Notes

- Existing OpenAI, DeepSeek, and Ollama profiles, credentials, model discovery, selection, and translation behavior remain unchanged.
- Claude requires a separately supplied API key and an exact model ID. Compatible endpoints must implement the required non-streaming Claude Messages behavior; a model-list endpoint is optional when a custom model ID is used.

# SubTandem v0.2.1

## Improvements

- Clearer **API root**, **Model ID**, and **Network route** guidance across OpenAI, Claude, DeepSeek, and Ollama. The translation request address updates as you edit the API root and wraps in narrow sidebars.
- Updated model examples and guidance recommending low-effort models. You can still enter any exact **Model ID**.
- Changing **Service type** now resets **Profile name** to the selected service's name.
- New Profiles use **Use system proxy settings** by default. Saved routes and draft route choices are preserved when switching services.
- Removed the subtitle beneath **New profile**.

## Upgrade and Compatibility Notes

- For the official OpenAI service, use `https://api.openai.com` as the **API root**; for Claude, use `https://api.anthropic.com`. Check existing Profiles when upgrading, since saved API roots remain unchanged until you edit and save them. For compatible services, confirm the translation request URL shown in the editor.

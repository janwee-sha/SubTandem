# SubTandem v0.1.0

## New Features

- Translate the selected local embedded SubRip, ASS, SSA, or `mov_text` track, or an external SRT or ASS subtitle, while IINA keeps displaying the original subtitle unchanged.
- Display translated cues in a non-interactive overlay whose vertical position can be adjusted without occupying or switching IINA subtitle tracks.
- Create, test, select, edit, and delete OpenAI and Ollama translation profiles. Profiles support discovered models, exact custom model IDs, custom HTTP or HTTPS endpoints, and either macOS proxy settings or a direct connection.
- Refresh available models when IINA starts, when SubTandem opens, when a valid endpoint changes, or when you request a refresh manually. Failed or stale refreshes do not replace the current model selection.
- Detect the source language when possible, let you confirm it when needed, and skip translation when the source and target languages match.
- Translate only nearby subtitle text through the profile you explicitly select, progressively publish completed cues, preserve cue alignment across reordered responses, and reuse successful results within the current video session.
- Run multiple IINA windows independently, including profile selection, translation state, helper processes, caches, temporary extraction data, and overlay output.

## Improvements

- Store optional provider credentials in the plugin's private local data directory with write-only behavior after saving. Credentials, subtitle text, and translations are excluded from diagnostics and release artifacts.
- Keep playback and original subtitles responsive when extraction, model discovery, translation, or a provider fails, with retryable status shown in the sidebar.
- Bundle signed universal native helpers and the required FFmpeg components, so supported local embedded subtitle extraction does not require a separate `ffmpeg` or `ffprobe` installation.

## Upgrade and Compatibility Notes

- Settings, profiles, credentials, helper processes, and temporary extraction data remain isolated within SubTandem's private plugin identity.
- This release requires macOS 12 or later and IINA 1.4.0 or later.
- Remote embedded subtitles, image-based subtitles, hardcoded subtitles, audio transcription, full-video pretranslation, export, cloud synchronization, and persistent translation caches are not supported.
- A compatible OpenAI or Ollama service and model must be supplied separately. The selected provider may charge for requests under its own terms.

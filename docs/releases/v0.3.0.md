# SubTandem v0.3.0

## New Features

- SubTandem now follows IINA’s interface language on IINA 1.5.0 or later, covering all 31 language variants shipped with IINA 1.5.0. Controls, status and error messages, accessibility text, and the plugin description use that language, with a right-to-left layout for Hebrew. Restart IINA after changing its application language; no separate plugin language setting is needed. Older hosts, unsupported languages, and unavailable language information use English, and missing translations fall back to English individually.
- Target languages, fonts, named color presets, and discovered models are sorted for the interface language. **Custom model ID…** stays first in every service’s model list. Changing the interface language preserves your translation target, font, and colors; the available subtitle translation targets remain unchanged.
- Font and color pickers follow the same interface language. System-provided picker text uses that language when macOS supplies it and otherwise falls back to an available system language.

## Bug Fixes

- Fixed punctuation and reading order in right-to-left subtitle translations, including Arabic and Hebrew. Sentence-ending punctuation, parentheses, numbers, and mixed text now follow the translation target’s direction, independently of the interface language.

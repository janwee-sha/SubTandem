69 个自然主样本的四类结果为：正确 63、错误 2、`unknown` 0、`unsupported` 4。四个自然范围外单语样本正确返回 `unsupported`，该类别不并入正确识别数。罗马字派生与稀少文字的误判仍逐项报告，没有因保留翻译候选而算作正确。

- 在扫描、取样、分类及聚合阶段分别触发换轨、换片、正文改变、禁用和关窗；旧 attempt 均零提交、零请求。关窗清理字幕证据和翻译缓存；IINA 复用播放器上下文时重新检测，新媒体不复用旧结果。宿主退出后停止定时器并关闭 controller。
- 2026-09-10 用户明确要求保留正文调试、继续使用 Log Viewer、不限制字幕正文和译文写入磁盘。宪法 III（5.0.0）及 FR-012 已对齐；正文、上下文与译文继续通过原调试输出进入 IINA 日志，允许宿主按设置持久化，不作为翻译缓存复用。凭据、候选列表、路径和原始标签仍不得进入诊断。
- 独立安全测试验证 Main 检测离线、只向已选 Profile revision 发送附近正文、安全计时白名单、本地工具仅监听回环地址、探测／翻译计数区分，以及宿主计时输入不回显。

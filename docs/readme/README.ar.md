يترجم SubTandem مسار الترجمة النصية المضمّن في ملف محلي أو ملف SRT/ASS الخارجي المحدد حاليًا في [IINA](https://iina.io/)، ويرسم الترجمة بنفسه في طبقة مستقلة. لا يعالج إلا نطاقًا قصيرًا أمام موضع التشغيل، ويترجم على دفعات محدودة. يستمر تشغيل الفيديو وعرض الترجمة الأصلية حتى إذا تأخرت الترجمة أو فشلت.

## 🎬 النتيجة أثناء الاستخدام

يُبقي SubTandem الترجمة الأصلية ظاهرة، ويعرض النص المترجم بشكل مستقل في الموضع الذي تختاره.

## ✨ الميزات

- **ترجمة نصية ثنائية اللغة وفورية:** تبقى الترجمة الأصلية محددة في IINA، بينما يرسم SubTandem الترجمة في المنتصف أفقيًا عند الموضع الرأسي الذي تختاره من دون شغل مسار ترجمة آخر.
- **نمط ثابت للنص المترجم:** اضبط لون Font وSize والخط وBold/Italic، ولون Border وWidth، ولون Background ضمن **Subtitle**. القيم الافتراضية هي نص أبيض بحجم 40 وخط النظام، وحد أسود بعرض 3، وخلفية شفافة. تشترك الألوان الثلاثة في الإعدادات المسبقة و**Show Colors…** مع الشفافية؛ وإذا تعذر توفر خط محفوظ، يُستخدم خط النظام مؤقتًا ويُستعاد الخط تلقائيًا عند توفره.
- **دعم الترجمة النصية المضمّنة والخارجية:** يدعم Matroska SubRip/ASS/SSA وMOV/MP4 `mov_text` المحلية وملفات SRT/ASS الخارجية. تتضمن الحزمة أداة الاستخراج ولا تحتاج إلى `ffmpeg` أو `ffprobe` خارجي.
- **اختيار خدمة الترجمة:** استخدم OpenAI أو Claude أو DeepSeek أو Ollama. ويمكنك أيضًا الاتصال بخدمات متوافقة مع OpenAI أو Claude.
- **أولوية التشغيل:** لا توقف عملية الترجمة الفيديو ولا تخفي الترجمة الأصلية.
- **طلبات محدودة:** يترجم SubTandem مقاطع cue القريبة فقط، ويحد من العمل المتزامن لكل نافذة تشغيل، ويخزن النتائج الناجحة مؤقتًا لجلسة الفيديو الحالية فقط.
- **عدة Profile:** وسّع Profile داخل القائمة المجمعة لتحريره في مكانه، أو استخدم **New profile** بجانب العنوان. يختبر Test مسودة الدرج الحالية، ولا يفعّل المراجعة المحفوظة الدقيقة في كل النوافذ إلا المفتاح المستقل.
- **التحكم في الوكيل:** تستخدم Profile الجديدة الاتصال المباشر افتراضيًا، ويمكن تغييرها لاستخدام إعدادات proxy الحالية في macOS.

## ✅ المتطلبات

- macOS 12 أو أحدث
- IINA 1.4.0 أو أحدث
- مسار ترجمة نصية مضمّن محلي ومدعوم، أو ملف SRT/ASS/SSA خارجي قابل للقراءة
- خدمة OpenAI أو Claude أو DeepSeek أو Ollama مع نموذج يمكنك استخدامه. ترد خطوات إعداد كل خدمة أدناه.

لا يقوم SubTandem بتنزيل نماذج الترجمة أو تشغيلها.

## 🚀 التثبيت

افتح IINA وانتقل إلى **Settings → Plugins**. تدعم واجهة إدارة الإضافات طرق التثبيت التالية.

<div align="center">

![واجهة إدارة إضافات IINA وبها زرا التثبيت من GitHub وتثبيت الحزمة](assets/plugin-manager.webp)

</div>

### التثبيت من GitHub (موصى به)

1. انقر **Install from GitHub…**.
2. أدخل `janwee-sha/SubTandem` في حقل `user/repo`، ثم أكد التثبيت.
3. انتظر حتى يظهر SubTandem في قائمة الإضافات المثبتة.

<div align="center">

![مربع حوار IINA لتثبيت SubTandem من GitHub](assets/install_from_github.webp)

</div>

يتضمن SubTandem v0.1.0 بيانات تحديث IINA. ثبّته بأي من الطرق المذكورة أعلاه كي يتمكن IINA من التحقق من الإصدارات اللاحقة وتثبيتها.

### تثبيت حزمة تم تنزيلها

1. افتح صفحة [Releases](https://github.com/janwee-sha/SubTandem/releases) ونزّل أحدث حزمة `SubTandem-X.Y.Z.iinaplgz`.
2. ارجع إلى **Settings → Plugins** وانقر **Install Package…**.
3. اختر ملف `.iinaplgz` الذي نزّلته وأكد التثبيت.

### التثبيت من قائمة الإضافات (إصدار IINA التطويري)

تتيح إصدارات IINA التطويرية تثبيت SubTandem مباشرة من قائمة الإضافات المتاحة.

1. افتح **Settings → Plugins**، ثم افتح مربع حوار تثبيت إضافة جديدة.
2. اختر **SubTandem** من قائمة الإضافات المتاحة.
3. أكد التثبيت وانتظر حتى يظهر SubTandem في قائمة الإضافات المثبتة.

<div align="center">

![تحديد SubTandem في قائمة الإضافات المتاحة في إصدار IINA التطويري](assets/install_from_plugins_list.webp)

</div>

أيًا كانت طريقة التثبيت، وافق على أذونات الإضافة المطلوبة إذا ظهرت، وتأكد من تفعيل مربع الاختيار بجوار SubTandem، ثم أعد تشغيل IINA. بعد ذلك شغّل فيديو، وافتح الشريط الجانبي في IINA، واختر تبويب **SubTandem**.

## 🌍 البدء السريع

1. افتح فيديو محليًا وحدد مسارًا نصيًا مضمّنًا ومدعومًا أو ملف SRT/ASS خارجيًا بوصفه الترجمة الأساسية في IINA.
2. ضمن **Subtitle**، اختر اللغة الهدف الدقيقة. تفهم خدمة الترجمة المحددة لغة المصدر لكل cue داخل طلب الترجمة، لذلك لا يلزم تأكيد لغة المصدر يدويًا.
3. ضمن **Translation service**، اختر **New profile** وأنشئ Profile من نوع OpenAI أو Claude أو DeepSeek أو Ollama. تستخدم المسودة الجديدة **Connect directly** افتراضيًا. أدخل API key عند الحاجة ثم حدّث قائمة النماذج يدويًا.
4. استخدم **Test** أسفل اليسار لاختبار المسودة الحالية من دون حفظها، ثم **Save** أسفل اليمين وفعّل المفتاح المستقل. قد تُحتسب تكلفة لطلب Test الثابت، لكنه لا يرسل نص الترجمة الجاري ولا يحفظ key الجديدة ولا يفعّل Profile.
5. فعّل **Translate**. تبقى الترجمة الأصلية معروضة في IINA، وتظهر مقاطع cue المترجمة في طبقة SubTandem. استخدم **Position** ضمن **Subtitle** لنقل الطبقة من الأعلى (`0`) إلى الأسفل (`100`).
6. اضبط قيم النمط الثماني في مجموعات **Font** و**Border** و**Background**. يؤدي اختيار لون مسبق إلى الحفظ مباشرة؛ ويفتح **Show Colors…** لوحة ألوان macOS، بينما يحافظ إغلاقها من دون تغيير على القيمة السابقة.

وسّع ملخص Profile لتحريره في مكانه. يظهر **Test** يسار صف الإجراءات، وتظهر **Cancel** و**Delete** و**Save** بهذا الترتيب يمينًا؛ ولا تعرض المسودة الجديدة Delete. اختبر القيم الحالية واحفظها ثم فعّل المراجعة الجديدة.

## ⚙️ خدمات الترجمة

### OpenAI

- عنوان API root الافتراضي هو `https://api.openai.com/v1`. عند استخدام خدمة OpenAI الرسمية، أدخل **API key** واختر نموذجًا متاحًا لحسابك.
- حدّث قائمة النماذج واختر نموذجًا، أو أدخل **Model ID** الدقيق له.
- لاستخدام خدمة متوافقة مع OpenAI، غيّر **Endpoint** إلى API root الخاص بها. يضيف SubTandem المسار `/chat/completions` ويعرض عنوان الطلب في الشريط الجانبي. اترك **API key** فارغًا إذا كانت الخدمة تقبل الطلبات من دونه.

### Claude

- عنوان API root الافتراضي هو `https://api.anthropic.com`. عند استخدام خدمة Claude الرسمية، أدخل **API key** من Anthropic واختر نموذجًا متاحًا لحسابك.
- حدّث قائمة النماذج واختر نموذجًا، أو أدخل **Model ID** الدقيق له.
- لاستخدام خدمة متوافقة مع Claude، غيّر **Endpoint** إلى API root الخاص بها. يستخدم SubTandem المسار `/v1/messages` للترجمة و`/v1/models` لقائمة النماذج. اترك **API key** فارغًا إذا كانت الخدمة تقبل الطلبات من دونه. يمكنك تحديث النماذج واختبار Profile وحفظه وتفعيله بدون مفتاح.

### DeepSeek

- عنوان API root الافتراضي هو `https://api.deepseek.com`. عند استخدام خدمة DeepSeek الرسمية، أدخل **API key** واختر نموذجًا متاحًا لحسابك.
- حدّث قائمة النماذج واختر نموذجًا، أو أدخل **Model ID** الدقيق له. لا يختار SubTandem نموذج DeepSeek تلقائيًا.
- إذا كانت خدمتك تستخدم API root متوافقًا آخر، فغيّر **Endpoint**. يضيف SubTandem المسار `/chat/completions` للترجمة.

### Ollama

- عنوان الخادم الافتراضي هو `http://127.0.0.1:11434` لخدمة Ollama التي تعمل على جهازك. شغّل Ollama وثبّت نموذجًا متوافقًا أولًا.
- حدّث قائمة النماذج واختر نموذجًا مثبتًا، أو أدخل **Model ID** الدقيق له.
- لاستخدام خادم Ollama بعيد، غيّر **Endpoint** إلى عنوان الخادم. أدخل **API key** فقط إذا كان الخادم يطلبه. يفحص **Test** الاتصال والنموذج ودعم المخرجات المنظمة.

تستخدم Profile الجديدة **Connect directly** افتراضيًا. اختر **Use macOS proxy settings** إذا كانت شبكتك تحتاج إلى وكيل. لا تُعرض API key المحفوظة مرة أخرى.

## 🔒 الخصوصية وبيانات الاعتماد والتكلفة

- لا يرسل SubTandem إلى Profile الذي حددته صراحة إلا نص cue القريب واللغة الهدف الدقيقة ومعرّفات cue غير الدلالية وقدرًا محدودًا من السياق المجاور. تفهم الخدمة لغة المصدر داخل طلب الترجمة نفسه، ولا يُرسل محتوى الفيديو أو الصوت.
- تُستخدم صلاحية `video-overlay` لعرض الترجمة الحالية في Overlay محلي غير تفاعلي. لا يقبل Overlay الإدخال أو السحب فوق الفيديو، ولا يستخدم الشبكة أو تخزين WebView، ويُمسح مع جلسة التشغيل.
- يحفظ ملف الإضافة الخاص `credentials.json` بيانات Profile ومرجع Profile المفعّل عالميًا وAPI key الخاصة بـOpenAI وClaude وDeepSeek وOllama في مستند محلي واحد يُستبدل ذريًا. تبقى key نصًا واضحًا؛ يستخدم المجلد صلاحية `0700` والملف `0600`. لا تُكتب key في IINA preferences أو السجلات أو التشخيص أو حالة Sidebar أو الحزمة، ولا تُعرض مرة أخرى بعد الحفظ.
- تحمي صلاحيات الملف key من حسابات macOS الأخرى ومن الوصول العرضي المعتاد، لكنها لا تحميها من عملية تستطيع أصلًا قراءة الملفات بصلاحيات مستخدم macOS الحالي.
- يستمع transport helper المرفق إلى منفذ مؤقت على `127.0.0.1` فقط. قد يتلقى endpoint المحفوظ أو الجاري تعديله طلبات قائمة نماذج بلا نص ترجمة. يرسل **Test** إلى المسودة الحالية probe ثابتًا بلا ترجمة قد يكون مدفوعًا؛ ولا تُستخدم key الجديدة إلا لهذا الاختبار ما لم تُحفظ منفصلة. ولا تتلقى نص الترجمة إلا مراجعة Profile المفعّلة عالميًا.
- تُخزن الترجمات مؤقتًا لجلسة الفيديو الحالية فقط، وتُمسح عند تغيير الفيديو أو انتهاء التشغيل أو إغلاق النافذة.
- تستمر المسارات القصيرة والنصوص مجهولة اللغة المصدر والنصوص المطابقة أصلًا للغة الهدف الدقيقة في الإرسال إلى الخدمة المحددة، وقد تُفرض عليها رسوم. تطبق الخدمة سياساتها الخاصة؛ ويقلل التجميع وذاكرة الجلسة المؤقتة عدد الطلبات من دون ضمان حد أقصى للتكلفة.

## 📌 النطاق الحالي

لا يوفر SubTandem نسخ الصوت، أو OCR/استخراج الترجمة الرسومية، أو استخراج الترجمة المضمّنة من الوسائط البعيدة، أو الترجمة المسبقة للفيديو كاملًا، أو تصدير الترجمة، أو المزامنة السحابية، أو التخزين الدائم للترجمات. تُحذف بيانات الاستخراج المؤقتة بعد التحليل أو الإلغاء أو انتهاء المهلة أو إغلاق الجلسة.

## 🛠️ استكشاف الأخطاء

- **Select a supported text subtitle:** حدد SubRip/ASS/SSA/`mov_text` مضمّنًا محليًا أو SRT/ASS خارجيًا بوصفه المسار الأساسي. لا تُدعم الترجمة الرسومية أو المضمّنة في الوسائط البعيدة؛ اتبع الحالة لإعادة تحديد المسار أو Retry بعد فشل التحضير.
- **فشل الترجمة:** اتبع الإجراء المحدد الظاهر في Session. وبحسب سبب الفشل، اختبر Profile وتحقق من endpoint وModel ID الدقيق وAPI key ومسار الشبكة وحدود الحساب أو عملية Ollama. يستمر التشغيل وتبقى الترجمة الأصلية ظاهرة بصورة طبيعية.
- **Credential could not be saved:** ثبّت حزمة Release بدلًا من نسخة تطوير ناقصة، وتأكد من إمكانية الكتابة في مجلد بيانات الإضافة، ثم أغلق IINA بالكامل وأعد تشغيله.
- **لا تظهر الترجمة المرسومة:** تأكد من تفعيل مفتاح Profile المقصود و**Translate** معًا، وأن موضع التشغيل يقع ضمن توقيت cue تتوفر له ترجمة.
- **مشكلة في الشبكة أو الوكيل:** تتصل Profile الجديدة مباشرةً. إذا كانت شبكتك تحتاج إلى وكيل، فاختر **Use macOS proxy settings** لهذه Profile، ثم احفظها واختبرها وفعّل المراجعة الجديدة.

## ☕ دعم SubTandem

إذا كان SubTandem مفيدًا لك، يمكنك طوعًا شراء فنجان قهوة للمطوّر عبر [Afdian](https://www.ifdian.net/item/ea1ff37a97ed11f19a9f52540025c377?utm_source=copylink&utm_medium=link) أو [Ko-fi](https://ko-fi.com/ianhsia).

يبقى SubTandem مجانيًا وبكامل الميزات للجميع. لا يفتح الدعم ميزات إضافية أو ترجمة ذات أولوية أو إصدارات حصرية، ولا يشمل رصيد API لخدمة الترجمة. قد يفرض المزوّد الذي تختاره رسومًا منفصلة وفقًا لشروطه وسياسات المحتوى الخاصة به.
